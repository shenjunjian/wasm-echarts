# 官网折线缺口补齐计划

范围只覆盖[上一轮折线示例对照](https://echarts.apache.org/examples/zh/index.html#chart-type-line)里暴露的能力，不顺便做 Radar/Map/Gauge 等无关图表。禁止改 `echarts-master/`、`zrender-master/`；wasm-echarts **不** path 依赖 wasm-zrender。实现变更必须同步 [AGENT.md](AGENT.md) 与 [site/echarts/docs/index.html](wasm-echarts-rs/site/echarts/docs/index.html) 的「已实现 / 未实现」表。

当前卡点分两类：

- **抛错（10 例）**：JS 命名空间 / 实例方法缺失，option 还没进渲染器就挂了。
- **静默忽略（约 30 例能跑）**：option 被吃掉，但 [`chart/line.rs`](wasm-echarts-rs/crates/wasm-echarts/src/chart/line.rs) 只画直线 Polyline + 纯色 stroke。

底层 [`rust-zrender`](wasm-echarts-rs/crates/rust-zrender) **已经有** `PolylineShape.smooth`、`PolygonShape` 填充、`FillStrokeStyle::LinearGradient`。缺口在 wasm-echarts 的 option 语义层和 JS facade。

```mermaid
flowchart LR
  option["setOption"] --> facade["js facade graphic util time"]
  facade --> parse["OptionValue + SeriesModel"]
  parse --> lineView["chart/line.rs"]
  lineView --> zr["rust-zrender Polyline Polygon Gradient"]
```

验收基准：[`site/scripts/probe-official-line.mjs`](wasm-echarts-rs/site/scripts/probe-official-line.mjs) 对 40 例跑一遍；每波结束更新「仍报错 / 视觉仍缺」清单。画廊预览以 iframe 实际出图为准。

---

## 第 1 波：挡住出图的 JS API（优先）

目标：把 10 个抛错例里 **不依赖新 ChartView** 的先救活。实现放在 [`crates/wasm-echarts/js/`](wasm-echarts-rs/crates/wasm-echarts/js/)，从 [`index.js`](wasm-echarts-rs/crates/wasm-echarts/js/index.js) 按官方 `export/api.ts` 再导出 `graphic` / `util` / `time`。按签名重写，不整文件复制官方代码。可对照（禁止 copy）[`wasm-zrender/js/tool/util.js`](wasm-echarts-rs/crates/wasm-zrender/js/tool/util.js) 的 `each`、[`zrender LinearGradient` 构造](echarts-master/src/util/graphic.ts)。

**`echarts.graphic`**

- 最小集：`LinearGradient(x, y, x2, y2, colorStops?, globalCoord?)`、`RadialGradient`、以及 fisheye 用到的 `Rect`。
- 实例要能被 `parse_option_value` 收成带 `type: 'linear'` / `colorStops` 的对象（可枚举字段），供第 2 波 Rust 侧读。
- `Rect` 先做 JS 侧形状对象（`setShape` / `ignore` / 可 add 到 Zr 见第 4 波）；本波只要 `new echarts.graphic.LinearGradient(...)` 不再抛错。

**`echarts.util.each(arr, cb, context?)`**：数组 / 类数组 / 对象遍历，对齐 zrender `util.each`。救活 `line-race`。

**`echarts.time.format` / `roundTime` / `parse`**：按 [`echarts-master/src/util/time.ts`](echarts-master/src/util/time.ts) 签名重写最小实现（模板 `{yyyy}{MM}{dd}`、按 year/month/day/hour 向下取整）。救活 `intraday-breaks-*`、`matrix-sparkline` 的 **脚本阶段**（矩阵图本身仍空，见第 4 波）。

**实例方法（facade，不引入 DOM Loading 组件）**

- `showLoading` / `hideLoading`：空操作 + 可选 `console.info`（与「无 DOM 组件」例外一致，只保证不抛）。救活 `confidence-band` 进入 `setOption`。
- `containPixel('grid', [x,y])`：复用已有 cartesian grid 矩形判断（[`coord/mod.rs`](wasm-echarts-rs/crates/wasm-echarts/src/coord/mod.rs) 已有 grid 范围）。
- **本波不做 `getZr()`**（crate 隔离硬规则）。`line-pen` / `line-fisheye-lens` 仍报错，放到第 4 波用 wasm-echarts 自有 Zr 薄封装。

本波结束后：`area-stack-gradient` / `area-simple` / `line-tooltip-touch` 应能进入渲染（可能仍无面积渐变，直到第 2 波）；`line-race` / `confidence-band` 不再死在 util/loading。

官方示例宿主 [`official-runtime.js`](wasm-echarts-rs/site/src/echarts/official-runtime.js) 对已真实导出的命名空间不要再套抛错 Proxy。

## 第 2 波：折线 ChartView 视觉（smooth / area / stack / step / 渐变）

改 Rust，核心文件：

- [`chart/line.rs`](wasm-echarts-rs/crates/wasm-echarts/src/chart/line.rs)：画面积 Polygon + 把 `PolylineShape.smooth` 接上；`step` 先把点列展开成阶梯再画。
- [`model/series.rs`](wasm-echarts-rs/crates/wasm-echarts/src/model/series.rs) + [`model/mod.rs`](wasm-echarts-rs/crates/wasm-echarts/src/model/mod.rs)：读 `smooth` / `step` / `stack` / `areaStyle` / `lineStyle.width`。
- [`visual/mod.rs`](wasm-echarts-rs/crates/wasm-echarts/src/visual/mod.rs) + [`bridge/resolve.rs`](wasm-echarts-rs/crates/wasm-echarts/src/bridge/resolve.rs)：颜色从纯 `String` 扩展为能解析 linear gradient `OptionValue` → `FillStrokeStyle::LinearGradient`。
- 双数值轴折线：`xAxis.type === 'value'` 时用 `DataPoint.x_value` + `value_to_point`（与 scatter 相同），修正 `line-in-cartesian-coordinate-system` 用下标当 x 的问题。

**stack**：同一 `stack` id 的 line 系列按声明顺序累加 y（面积用「当前堆顶 / 前一堆顶」两条边界围成 Polygon）。与 bar 可共用一个 `stack_offset` 计算，但本波只接线 line。

**areaStyle**：无 stack 时从折线点落到 y=0（或 `yAxis.min` 基线）闭合。`areaStyle.color` 支持纯色和 `LinearGradient`。

**sampling: 'lttb'`**：`area-simple` 2 万点；在映射像素前做 LTTB 降采样，避免渐变修好后卡死。

本波验收示例：`line-smooth`、`area-basic`、`area-stack`、`area-stack-gradient`、`line-step`、`line-stack`、`area-simple`、`line-tooltip-touch`。

## 第 3 波：标记、轴类型、多轴（仍在 cartesian）

- **markLine / markPoint**：从 series option 读 `yAxis: number` / `type: 'average'|'max'|'min'` / 坐标点，画 `Line` + 简单 symbol/label。救活 `line-marker`、`line-markline`、`line-aqi` 的标线（现在能跑但看不见标记）。
- **endLabel**：最后一个可见点旁画 Text（`line-race` 在 dataset 之后才完整）。
- **AxisType 增加 `Log` / `Time`**（[`model/axis.rs`](wasm-echarts-rs/crates/wasm-echarts/src/model/axis.rs) 目前只有 Category/Value）：
  - log：`y_value_to_pixel` 用 `ln`；非法值跳过。
  - time：把类目/`[date, value]` 解析成时间戳，当 value 轴线性映射；轴标签用第 1 波的 `time.format` 或 Rust 侧简易年月日。
- **多 x/y 轴、多 grid**：`first_component` 改为按 `xAxisIndex` / `yAxisIndex` / `gridIndex` 取对应轴；`line-easing`、`grid-multiple`、`multiple-x-axis` 才能各占一格。不做完整 media query。

明确不做：toolbox 图标条、slider dataZoom UI（inside 滚轮已有）、`tooltip.trigger: 'axis'` 完整轴提示（可后置）。

## 第 4 波：大件（polar / dataset / graphic / getZr）

按收益单独开干，互不阻塞前三波。

**dataset + transform filter**

- 读 `option.dataset` source，按 `series.datasetId` / `encode` / `seriesLayoutBy: 'row'` 生成 `series.data`。
- `transform.type: 'filter'` 做最小配置（dimension + gte / `=`）。
- 救活 `dataset-link`、`data-transform-filter`、`line-race` 的真正曲线。

**polar**

- 新 coord：`angleAxis` + `radiusAxis` → 像素；`coordinateSystem: 'polar'` 的 line 走它而不是 cartesian。
- 验收 `line-polar` / `line-polar2`。

**visualMap.pieces**

- 按 y 值分段改 line/item 颜色（`line-aqi`、`area-pieces`、`line-sections`、`line-gradient`）。不做完整 visualMap 组件 UI 也可先只做「按 pieces 上色」。

**getZr 薄封装（不依赖 wasm-zrender）**

- wasm-echarts 已经持有 `rust_zrender::ZRenderer`。在 facade 上提供 **最小 Zr**：`on('click'|'mousedown'|'mousemove')`、`add`/`remove`、`setCursorStyle`，图元仅 `Rect` + 已有 Path。
- 文档写清：不是完整 zrender 实例，没有 SVG painter / hover layer。
- 救活 `line-pen`、`line-fisheye-lens` 的交互脚本；axis break / fisheye 放大本身仍可后置。

**option.graphic 组件**

- 把 `option.graphic` 里的 group/rect/text 画进同一 ZRenderer（[`line-graphic`](wasm-echarts-rs/site/echarts/examples/line-graphic.js) 水印）。与 getZr 动态 add 共用图元创建。

**仍可明确后置（本计划不承诺）**

- `matrix` 坐标系 / candlestick / axis `breaks` / toolbox 按钮 / legend 点击筛选 / `appendData` 动画竞速语义。这些即使第 1 波过了脚本，画面也不会对齐官网。
