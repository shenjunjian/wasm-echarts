wasm-echarts 文档

公开 JS API 对齐官方 ECharts canvas 用法（init / setOption）。 从 @wasm-echarts（js/ facade）导入；pkg/ 只作内部 handle。 入口签名见仓库 .cursor/plans/wasm-echarts_api_对齐_1d164d7d.plan.md； canvas 能力补齐见 .cursor/plans/echarts_canvas_全量对齐_3ceaa41e.plan.md。

快速开始

cd crates/wasm-echarts && wasm-pack build --target web

cd ../..
cd site && npm install && npm run dev
# 打开 http://127.0.0.1:5173/echarts/examples/
import initWasm, { init, registerFont } from '@wasm-echarts';

await initWasm();

const bytes = new Uint8Array(
  await (await fetch('/fonts/NotoSansSC-Regular.ttf')).arrayBuffer()
);
registerFont(bytes, {
  familyName: 'Noto Sans SC',
  sansSerif: ['Noto Sans SC'],
});

const canvas = document.getElementById('canvas');
canvas.width = 480;
canvas.height = 360;

const chart = init(canvas);
chart.setOption({
  tooltip: { trigger: 'item' },
  xAxis: { type: 'category', data: ['Mon', 'Tue', 'Wed'] },
  yAxis: { type: 'value' },
  series: [{ type: 'line', name: '销量', data: [120, 200, 150] }],
});
chart.on('click', (params) => {
  console.log(params.seriesIndex, params.dataIndex);
});

1. 与官方一致的公开 API

可按官方文档调用（签名对齐）。default export 仍是 wasm-bindgen 的 initWasm，命名导出才是 echarts API。

导出 / 方法签名与说明
init init(canvas, theme?, opts?)。有 canvas 时 setOption 自动上屏，并绑定 mousemove / click / leave / wheel。init(null, null, { width, height, devicePixelRatio }) 允许离屏（见例外）。
dispose dispose(chart | canvas | id)
getInstanceByDom / getInstanceById 按 canvas / id 取回实例
version '6.1.0'
use 导出且签名对齐；只打印提示，不按需加载（见例外）
setOption setOption(option) / setOption(option, notMerge, lazyUpdate?) / setOption(option, { notMerge, replaceMerge, silent, lazyUpdate })。notMerge 不是 option 字段。
getOption 已合并 option 转回普通 JSON；函数字段保留为原 Function
resize resize() 无参读 canvas；resize({ width, height, devicePixelRatio })；'auto' 回退到 canvas
clear 等价 setOption({ series: [] }, true)
on / off click / mouseover / mouseout / globalout。on(event, handler) 或 on(event, query, handler)。payload 含 event、seriesIndex、dataIndex。
dispatchAction 已接线：highlight / downplay / select / unselect / toggleSelect / dataZoom / showTip / hideTip / legendToggleSelect / legendSelect / legendUnSelect / restore / timelineChange / brush。其它 type console.warn。
getWidth / getHeight / getDevicePixelRatio / isDisposed / dispose / getDom / getId 实例生命周期与尺寸
convertToPixel / convertFromPixel cartesian 最小集：finder { xAxisIndex } / { yAxisIndex } / { gridIndex } / { seriesIndex } 或 'xAxis' / 'yAxis' / 'grid'
getZr 返回与 ChartView 共用 Storage 的 wasm-zrender 实例
showLoading / hideLoading 静态遮罩；不播旋转动画
getDataURL / renderToCanvas 离屏 RGBA → PNG/JPEG / 画到 canvas
containPixel / appendData / setTheme grid 包含判断；追加 series.data；应用已注册主题
connect / registerTheme / registerMap / getMap / registerTransform 按 group 转发 action；主题表；地图表结构（本波不画 map）；dataset 外部 transform
graphic / util / time / format / number / helper / matrix / vector / color / env 已从 wasm-zrender 再导出或按官方签名重写。LinearGradient 可进 setOption

2. 与官方不一致 / 例外

项现状 / 约定
use(...) 不加载模块，只 console.info：已开发的图表/组件都编进 WASM，不必 use
init(null) 允许离屏（官方客户端无 dom 会抛错）
渲染 仅 canvas；无 SVG / renderToSVGString / getSvgDataURL
动画 不播中间帧；setOption / animation 直接终态。lazyUpdate / silent 同步 flush
字体 WASM 不读系统字体。轴标签 / series label 渲染走 rust-zrender fontdb；须从 @wasm-echarts 调 registerFont。echarts 页与 getZr 共用同一份 fontdb；zrender 文档站的 pkg 仍是另一份内存。未注册时 refresh 会报 no default font found
notMerge 只作 setOption 第二参数；写在 option 根上不会当合并开关
replaceMerge 只按顶层 key 整段替换，不按 component id
getZr() 返回与 ChartView 共用 Storage 的 wasm-zrender 实例。不是第二份 zrender wasm；无 SVG painter / hover layer；动画终态
showLoading / hideLoading 导出；静态半透明遮罩 + 文案，不播官方旋转 Loading 动画
DataView / SaveAsImage toolbox DataView 浮层与 SaveAsImage 的 DOM 下载条明确不做
default export wasm-bindgen initWasm，不是 echarts 命名空间对象
tooltip facade 内建简单 string HTML DOM，不是官方 TooltipView；HTMLElement formatter 未实现

3. 多出来的非官方 API

因 WASM 离屏需要。不要当官方 API 用。init(canvas) 后普通用户不必再手动 putImageData，也不必再绑指针或自绘 tooltip。

方法何时用何时不要用
refresh() 离屏无 canvas，需要 RGBA 自行 putImageData init(canvas) 后 setOption 已自动上屏
findHover(x, y) 自管命中检测 主路径用 on('mouseover')
handlePointerMove(x, y) / handlePointerLeave() / handlePointerDown / handlePointerUp / handlePointerClick 离屏或自管指针 init(canvas) 时一般不需要
applyDataZoomWheel(x, deltaY) 自管滚轮 init(canvas) 时滚轮已绑定
getTooltipContent(si, di) 自绘 tooltip（string HTML） init(canvas) 时 facade 已内建 DOM
benchmarkRender(n) 渲染均值耗时（毫秒） 不是官方性能 API
hasOption / optionHasFunctions 状态查询 不是官方 API
registerFont(data, opts?) / clearFonts() 注册 TTF/OTF/WOFF/TTC bytes（opts.familyName、opts.sansSerif）；后续注册若未传 sansSerif 不会覆盖已有 sans-serif 映射。已创建实例会热更新 fontdb。轴标签渲染前必调。多字体见 fonts 不是官方 ECharts API；不要从 @wasm-zrender 注册并期望本模块生效

未实现（按 canvas 全量对齐计划补齐，不是永久例外）

下列官方入口已导出同名，内部只 console.warn：registerLocale / setPlatformAPI / registerPreprocessor。

实例上尚未做完：convertToLayout / getVisual。

  • Charts：Radar、Map、Gauge、Funnel、Heatmap、Custom renderItem 等其余类型。未接线的 series.type 不得静默忽略后永远不管。
  • Components：geo、polar、radar、singleAxis、calendar、matrix。toolbox DataView DOM / SaveAsImage 下载条明确不做。
  • Actions：geo roam 等
  • media query / 非 cartesian 的 convertToPixel finder
  • option 名字在但未按官方做：line polar / smoothMonotone、pie 完整 avoidLabelOverlap、色板不是官方 palette 全套
  • tooltip HTMLElement formatter / confine / renderMode: 'richText'

官网折线 40 例：第 3–4 波已把 canvas option 族与 mark* / graphic / slider / trigger: 'axis' 接到绘制。仍可能有视觉缺口（不在示例里 workaround）：polar、y 类目轴对调、smoothMonotone。这些归第 5 波。

函数 option

WASM 侧可识别 option 中的函数字段（如 tooltip.formatter、series[].itemStyle.color、axisLabel.formatter、symbolSize）， 在渲染/交互阶段回调。含函数的 option 见 交互合集。

实例对照（验收）

全部示例走 init(canvas) + setOption，不直接 new EChartsInstance。
