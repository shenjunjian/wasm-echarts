wasm-echarts 实例

wasm-echarts 文档

公开 JS API 对齐官方 ECharts canvas 用法（init / setOption）。 从 @wasm-echarts（js/ facade）导入；pkg/ 只作内部 handle。 逐项清单见仓库 .cursor/plans/wasm-echarts_api_对齐_1d164d7d.plan.md。

快速开始

cd crates/wasm-echarts && wasm-pack build --target web

cd ../..
cd site && npm install && npm run dev
# 打开 http://127.0.0.1:5173/echarts/examples/
import initWasm, { init, registerFont } from '@wasm-echarts';

await initWasm();

const bytes = new Uint8Array(
  await (await fetch('/fonts/NotoSansSC-Regular.ttf')).arrayBuffer()
);
registerFont(bytes, {
  familyName: 'Noto Sans SC',
  sansSerif: ['Noto Sans SC'],
});

const canvas = document.getElementById('canvas');
canvas.width = 480;
canvas.height = 360;

const chart = init(canvas);
chart.setOption({
  tooltip: { trigger: 'item' },
  xAxis: { type: 'category', data: ['Mon', 'Tue', 'Wed'] },
  yAxis: { type: 'value' },
  series: [{ type: 'line', name: '销量', data: [120, 200, 150] }],
});
chart.on('click', (params) => {
  console.log(params.seriesIndex, params.dataIndex);
});

1. 与官方一致的公开 API

可按官方文档调用（签名对齐）。default export 仍是 wasm-bindgen 的 initWasm，命名导出才是 echarts API。

导出 / 方法签名与说明
init init(canvas, theme?, opts?)。有 canvas 时 setOption 自动上屏，并绑定 mousemove / click / leave / wheel。init(null, null, { width, height, devicePixelRatio }) 允许离屏（见例外）。
dispose dispose(chart | canvas | id)
getInstanceByDom / getInstanceById 按 canvas / id 取回实例
version '6.1.0'
use 导出且签名对齐；只打印提示，不按需加载（见例外）
setOption setOption(option) / setOption(option, notMerge, lazyUpdate?) / setOption(option, { notMerge, replaceMerge, silent, lazyUpdate })。notMerge 不是 option 字段。
getOption 已合并 option 转回普通 JSON；函数字段保留为原 Function
resize resize() 无参读 canvas；resize({ width, height, devicePixelRatio })；'auto' 回退到 canvas
clear 等价 setOption({ series: [] }, true)
on / off click / mouseover / mouseout / globalout。on(event, handler) 或 on(event, query, handler)。payload 含 event、seriesIndex、dataIndex。
dispatchAction 已接线：highlight / downplay / select / unselect / toggleSelect / dataZoom / showTip / hideTip。其它 type console.warn。
getWidth / getHeight / getDevicePixelRatio / isDisposed / dispose / getDom / getId 实例生命周期与尺寸
convertToPixel / convertFromPixel cartesian 最小集：finder { xAxisIndex } / { yAxisIndex } / { gridIndex } / { seriesIndex } 或 'xAxis' / 'yAxis' / 'grid'

2. 与官方不一致 / 例外

项现状 / 约定
use(...) 不加载模块，只 console.info：已开发的图表/组件都编进 WASM，不必 use
init(null) 允许离屏（官方客户端无 dom 会抛错）
渲染 仅 canvas；无 SVG / renderToSVGString / getSvgDataURL
动画 不播中间帧；setOption / animation 直接终态。lazyUpdate / silent 同步 flush
字体 WASM 不读系统字体。轴标签 / series label 走 rust-zrender fontdb；须从 @wasm-echarts 调 registerFont（与 wasm-zrender 的 fontdb 不共享）。未注册时 refresh 会报 no default font found
notMerge 只作 setOption 第二参数；写在 option 根上不会当合并开关
replaceMerge 只按顶层 key 整段替换，不按 component id
getZr() 因 crate 隔离本波不导出
default export wasm-bindgen initWasm，不是 echarts 命名空间对象
tooltip facade 内建简单 string HTML DOM，不是官方 TooltipView；HTMLElement formatter 未实现

3. 多出来的非官方 API

因 WASM 离屏需要。不要当官方 API 用。init(canvas) 后普通用户不必再手动 putImageData，也不必再绑指针或自绘 tooltip。

方法何时用何时不要用
refresh() 离屏无 canvas，需要 RGBA 自行 putImageData init(canvas) 后 setOption 已自动上屏
findHover(x, y) 自管命中检测 主路径用 on('mouseover')
handlePointerMove(x, y) / handlePointerLeave() 离屏或自管指针 init(canvas) 时一般不需要
applyDataZoomWheel(x, deltaY) 自管滚轮 init(canvas) 时滚轮已绑定
getTooltipContent(si, di) 自绘 tooltip（string HTML） init(canvas) 时 facade 已内建 DOM
benchmarkRender(n) 渲染均值耗时（毫秒） 不是官方性能 API
hasOption / optionHasFunctions 状态查询 不是官方 API
registerFont(data, opts?) / clearFonts() 注册 TTF/OTF/WOFF bytes（opts.familyName、opts.sansSerif）；已创建实例会热更新 fontdb。轴标签渲染前必调 不是官方 ECharts API；不要从 @wasm-zrender 注册并期望本模块生效

4. 已实现 / 未实现

未实现（后置，不混进「已对齐」）

下列官方入口已导出同名，内部只 console.warn：connect / disconnect / registerTheme / registerMap / getMap / registerLocale / setPlatformAPI / registerPreprocessor。

实例上尚未导出（不要当已实现）：getZr / setTheme / appendData / getDataURL / renderToCanvas / showLoading / hideLoading / containPixel / convertToLayout / getVisual。

  • Charts：Radar、Map、Gauge、Funnel、Heatmap、Custom renderItem 等其余类型
  • Components：legend、title、toolbox、visualMap、geo、polar、graphic、brush、timeline、dataset
  • Actions：legend*、restore、brush、timeline、geo roam 等
  • connect / 主题 / registerMap / getZr / getDataURL / Loading / media query / convertToPixel 完整 finder
  • option 名字在但未按官方做：pie roseType、多 grid / 双 y 轴、symbol 仅 circle/rect/emptyCircle、色板不是官方 palette 全套
  • tooltip HTMLElement formatter / confine / trigger: 'axis'

函数 option

WASM 侧可识别 option 中的函数字段（如 tooltip.formatter、series[].itemStyle.color、axisLabel.formatter、symbolSize）， 在渲染/交互阶段回调。含函数的 option 见 交互合集。

实例对照（验收）

全部示例走 init(canvas) + setOption，不直接 new EChartsInstance。

示例覆盖
line / bar / pie / scatter init(canvas) 出图；轴 formatter、pie center/radius、symbol/label
merge 二次 setOption 深合并、notMerge: true、getOption、dispose 后再 init
interactive use() 只出提示；on('click') + dispatchAction('toggleSelect')；hover tooltip；wheel dataZoom。不必调 handlePointer*
bench 非官方 benchmarkRender
