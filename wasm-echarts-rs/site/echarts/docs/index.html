公开 JS API 对齐官方 ECharts canvas 用法（init / setOption）。 JS facade 尚未落地；当前实例仍 import native EChartsInstance。 逐项清单见仓库 .cursor/plans/wasm-echarts_api_对齐_1d164d7d.plan.md。

快速开始

cd crates/wasm-echarts && wasm-pack build --target web

cd ../..
cd site && npm install && npm run dev
# 打开 http://127.0.0.1:5173/echarts/examples/

1. 与官方一致的公开 API

下列为目标签名（须与官方同名同签名）。当前不可按此调用；波次 1 起由 js/ facade 落地。

  • init(canvas, theme?, opts?) — 创建实例；init(null, null, { width, height, devicePixelRatio }) 允许离屏
  • dispose(chart | canvas | id) / getInstanceByDom / getInstanceById
  • version — '6.1.0'
  • use(...) — 导出且签名对齐，只打印提示，不按需加载
  • 实例：setOption / getOption / resize / dispatchAction / on / off / getWidth / getHeight / getDevicePixelRatio / isDisposed / clear / dispose

2. 与官方不一致 / 例外

  • use(...) 不加载模块，只 console.info：已开发的图表/组件都编进 WASM，不必 use
  • init(null) 允许离屏（官方客户端无 dom 会抛错）
  • 仅 canvas；无 SVG / renderToSVGString / getSvgDataURL
  • 动画不播中间帧；lazyUpdate 同步执行
  • 字体须 registerFont；WASM 不读系统字体
  • getZr() 本波不导出（crate 隔离）
  • notMerge 当前被当 option 根字段剥掉（错误，将改为第二参数）

3. 多出来的非官方 API

因 WASM 离屏需要。不要当官方 API 用。init(canvas) 落地后，普通用户不必再调指针 hatch / 手动 putImageData。

import initWasm, { EChartsInstance } from '@wasm-echarts';

await initWasm();

const canvas = document.getElementById('canvas');
const width = 480;
const height = 360;
canvas.width = width;
canvas.height = height;

const chart = new EChartsInstance(width, height, 1);
chart.set_option({
  xAxis: { type: 'category', data: ['Mon', 'Tue', 'Wed'] },
  yAxis: { type: 'value' },
  series: [{ type: 'line', name: '销量', data: [120, 200, 150] }],
});

const rgba = chart.refresh();
const ctx = canvas.getContext('2d');
ctx.putImageData(
  new ImageData(new Uint8ClampedArray(rgba), chart.width(), chart.height()),
  0,
  0,
);
  • new EChartsInstance(w, h, dpr) — native 构造（目标：init）
  • set_option(option) — 设置 option（目标：setOption）
  • refresh() — 离屏绘制，返回 RGBA
  • handle_pointer_move(x, y) / handle_pointer_leave() — hover 高亮、axisPointer、tooltip 文本
  • find_hover(x, y) — 命中检测
  • dispatch_action(action) — toggleSelect / highlight 等
  • apply_data_zoom_wheel(x, deltaY) — inside dataZoom
  • get_tooltip_content(si, di) — 自绘 tooltip
  • benchmark_render(n) — 渲染均值耗时（毫秒）

4. 已实现 / 未实现

已实现（部分生效）

  • 图表：line、bar、pie、scatter（feature flag 写死在 rust，不是 echarts.use）
  • cartesian：单 x/y 轴；category / value；grid 边距
  • 交互：hover 高亮、toggleSelect、wheel inside dataZoom、竖线 axisPointer、string tooltip
  • 轴标签 Text（axisLabel.formatter 解析存在，轴侧调用待完善）
  • dispatchAction：highlight / downplay / select / unselect / toggleSelect / dataZoom

未实现（后置，不混进「已对齐」）

  • Charts：Radar、Map、Gauge、Funnel、Heatmap、Custom renderItem 等其余类型
  • Components：legend、title、toolbox、visualMap、geo、polar、graphic、brush、timeline、dataset
  • Actions：showTip / hideTip、legend*、restore 等
  • connect / 主题 / registerMap / getZr / getDataURL / Loading / media query
  • option 未按官方生效：pie radius/center、symbol/symbolSize、series label、多 grid / 双 y 轴

函数 option

WASM 侧可识别 option 中的函数字段（如 tooltip.formatter、series[].itemStyle.color）， 在渲染/交互阶段回调。含函数的 option 见 交互合集。
