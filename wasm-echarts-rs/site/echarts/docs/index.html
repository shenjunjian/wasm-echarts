快速上手

从 @wasm-echarts（js/ facade）导入，先加载 WASM，再 init / setOption。 pkg/ 是 wasm-bindgen 胶水，不是业务公开面。

pkg 与 JS facade

wasm-pack build --target web 产出 crates/wasm-echarts/pkg/ （wasm_echarts.js + .wasm）。这是内部 handle： EChartsInstance 没有官方实例包装，也不绑 canvas / tooltip。

公开入口是 crates/wasm-echarts/js/index.js。它包装 native handle，补上官方 init / setOption / on，以及 graphic / util 等命名空间。 文档站 Vite alias @wasm-echarts 指向这份 js/。

业务 / site → js/index.js → pkg/ → rust-zrender → RGBA

默认导出是 wasm-bindgen 的 initWasm；命名导出才是 echarts API。 不要直接 new EChartsInstance。仓库定位见 站点首页。

编译与启动

cd crates/wasm-echarts && wasm-pack build --target web

cd ../../site && npm install && npm run dev
# 打开 http://127.0.0.1:5173/echarts/examples/

改 Rust 引擎后必须重新 wasm-pack，浏览器才能拿到新逻辑。 更完整的 option 见 实例画廊。

推荐调用顺序

  1. await initWasm() — 加载 .wasm
  2. 有文字时 registerFont(bytes, opts?)（详见 字体引用）
  3. init(canvas | null, theme?, opts?)
  4. setOption(option)
宿主 行为
init(canvas) 绑指针与内建 string tooltip；setOption 后自动 putImageData
init(null, null, { width, height }) 纯离屏。尺寸来自 opts（缺省 300×150）；refresh() 返回 RGBA

默认主线程，setOption 同步返回。大数据再开 opts.useWorker，不要自己 new Worker。详见 运行模式。

示例：绑定 canvas

传入 HTMLCanvasElement 后，setOption 会自动把离屏 RGBA 贴上屏。 可对照 line。 

import initWasm, { init, registerFont } from '@wasm-echarts';

await initWasm();

const bytes = new Uint8Array(
  await (await fetch('/fonts/NotoSansSC-Regular.ttf')).arrayBuffer()
);
registerFont(bytes, {
  familyName: 'Noto Sans SC',
  sansSerif: ['Noto Sans SC'],
});

const canvas = document.getElementById('canvas');
canvas.width = 480;
canvas.height = 360;

const chart = init(canvas);
chart.setOption({
  tooltip: { trigger: 'item' },
  xAxis: { type: 'category', data: ['Mon', 'Tue', 'Wed'] },
  yAxis: { type: 'value' },
  series: [{ type: 'line', name: '销量', data: [120, 200, 150] }],
});
chart.on('click', (params) => {
  console.log(params.seriesIndex, params.dataIndex);
});

示例：纯离屏

init(null) 不绑 DOM，refresh() 同步返回 RGBA。 对照 坐标、导出与 getZr。 

import initWasm, { init, registerFont } from '@wasm-echarts';

await initWasm();
registerFont(fontBytes, { familyName: 'Noto Sans SC' });

const chart = init(null, null, { width: 480, height: 360 });
chart.setOption({
  xAxis: { type: 'category', data: ['A', 'B'] },
  yAxis: { type: 'value' },
  series: [{ type: 'bar', data: [12, 24] }],
});

const rgba = chart.refresh();
const ctx = canvas.getContext('2d');
ctx.putImageData(
  new ImageData(new Uint8ClampedArray(rgba), chart.getWidth(), chart.getHeight()),
  0,
  0,
);
