字体引用

WASM 离屏 cosmic-text 读不到操作系统字体。轴标签、series label、title、legend 都走这份 fontdb，必须从 @wasm-echarts 注册。

这是允许例外，不是可省略步骤。未注册任何字体时，含文字的 setOption / refresh() 会报 no default font found。

必须从本模块注册

echarts 页与 getZr() 共用同一份 WASM / fontdb。 不要从 @wasm-zrender 再 registerFont 并指望本模块生效： 那是另一份内存里的 wasm。

口径与 wasm-zrender 字体章 相同（离屏读不到 OS 字体、禁止把默认 TTF 打进 .wasm），只是入口换成 @wasm-echarts。

调用顺序

  1. await initWasm()
  2. registerFont(bytes, opts?) — TTF / OTF / WOFF（TTC 须带 familyName）
  3. init(...) → setOption

可在任意时刻再次调用。全局 fontdb 会同步到已创建的实例（热更新）。 useWorker 时 facade 把同一份 bytes postMessage 进 Worker： Worker 是另一份 WASM 实例，必须单独注入，开发者不必发第二份消息。

registerFont(data, opts?) 补充

参数 类型 说明
data Uint8Array 字体文件原始 bytes
opts.familyName string? 覆盖字体族名。不传则读字体 name table
opts.sansSerif string[]? 把 CSS sans-serif 映射到这些族名（按优先级）

clearFonts() 清空已注册字体，主要用于测试；同样会热更新已有实例， 并通知已创建的 Worker。

sans-serif 映射

  • 显式传 sansSerif：覆盖当前映射
  • 只传 familyName、且尚无映射：默认映射到该族名
  • 后续再注册其它字体且不传 sansSerif：不覆盖已有映射
import initWasm, { init, registerFont } from '@wasm-echarts';

await initWasm();

const bytes = new Uint8Array(
  await (await fetch('/fonts/NotoSansSC-Regular.ttf')).arrayBuffer()
);
registerFont(bytes, {
  familyName: 'Noto Sans SC',
  sansSerif: ['Noto Sans SC'],
});

const chart = init(canvas);
chart.setOption({
  title: { text: '中文标题', textStyle: { fontFamily: 'Noto Sans SC' } },
  xAxis: { type: 'category', data: ['一', '二'] },
  yAxis: { type: 'value' },
  series: [{ type: 'bar', data: [1, 2] }],
});

site 辅助，不是库 API

文档站提供 site/src/echarts/fonts.js，方便示例少写 fetch：

  • loadFontFromUrl(url, opts?)
  • ensureDefaultFont() — 拉取 /fonts/NotoSansSC-Regular.ttf

业务项目应自己 fetch 字体再调 facade 的 registerFont。 这不是 @wasm-echarts 的导出。
