事件与 dispatchAction

init(canvas) 后 facade 绑定指针。 发出官方事件名 click / mouseover / mouseout / globalout。

on / off 官方

on(event, handler) 或 on(event, query, handler)。 payload 含 event、seriesIndex、dataIndex。

参数 类型 说明
event string 指针事件，或 showTip / hideTip 等 action 事件
query string | object 可选过滤；不传则全部
handler Function 回调 
chart.on('click', (params) => {
  console.log(params.seriesIndex, params.dataIndex);
});
chart.off('click');

对照 interactive。

dispatchAction(payload) 官方

已接线的 type 会改交互状态并重绘。未接线 type console.warn。Worker 下已接线的返回 Promise。

type 行为
highlight / downplay emphasis 状态
select / unselect / toggleSelect 选中状态
dataZoom start / end 百分比
showTip / hideTip 按 seriesIndex / dataIndex 或 { x, y } 开关 string tooltip
legendToggleSelect / legendSelect / legendUnSelect 图例筛选
restore 恢复初始 option
timelineChange / timelinePlayChange 切 options[i] 后终态重绘
takeGlobalCursor 全局光标（brush 等）
brush / brushEnd 框选
expandAxisBreak / collapseAxisBreak / toggleAxisBreak 轴断点折叠；无展开动画

registerAction 登记的自定义 type 会先跑 handler，内建 type 仍走 native。

chart.dispatchAction({ type: 'toggleSelect', seriesIndex: 0, dataIndex: 1 });
chart.dispatchAction({ type: 'showTip', seriesIndex: 0, dataIndex: 0 });
