命名空间与扩展

export/api.ts 命名空间、主题 / 地图 / transform、以及扩展注册真表。 hatch 写清何时不该用。

命名空间 官方

已从 wasm-zrender 再导出或按官方签名重写。 LinearGradient 可进 setOption。

导出 说明
graphic 图元构造器 + 渐变 / Pattern；来自同一份 echarts WASM
util / number / time / format / helper 按官方签名的 JS 实现
matrix / vector / color 再导出 wasm-zrender js/tool/
env 环境探测对象
throttle(fn, delay?, debounce?) 按官方签名重写 
import { graphic, throttle } from '@wasm-echarts';
const color = new graphic.LinearGradient(0, 0, 0, 1, [
  { offset: 0, color: '#83bff6' },
  { offset: 1, color: '#188df0' },
]);

connect / disconnect 官方

按 chart.group 转发 dispatchAction。可传 group id，或实例数组。

connect([chartA, chartB]);
disconnect(chartA.group);

主题与地图 官方

方法 说明
registerTheme(name, theme) 登记主题表；init(dom, name) 或 setTheme 使用
registerMap(name, geoJson, specialAreas?) JS 表 + WASM 表；useWorker 时 facade 同步进 Worker
getMap(name) 读已登记记录
parseGeoJSON / parseGeoJson 返回 { name, center, polygons } 数组 
registerMap('demo', geoJson);
chart.setOption({
  geo: { map: 'demo' },
  series: [{ type: 'map', map: 'demo', data: [] }],
});

registerTransform({ type, transform }) 官方

内置 filter / sort；外部函数登记后可被 dataset 调用。包装后的 upstream 有 data / count / getRawDataItem 等。

registerTransform({
  type: 'my:filter',
  transform(params) {
    return { dimensions: params.upstream.dimensions, data: params.upstream.data };
  },
});

扩展注册 官方 降级

真表：registerPreprocessor / registerProcessor / registerLayout / registerVisual / registerAction / registerCoordinateSystem / registerCustomSeries / PRIORITY / setPlatformAPI。

layout / visual 的 ecModel 是简化对象（getOption / eachSeries），不是官方 GlobalModel / List。 

import { registerLayout, PRIORITY } from '@wasm-echarts';
registerLayout(PRIORITY.VISUAL.LAYOUT, (ecModel) => {
  ecModel.eachSeries((series) => { /* 简化模型 */ });
});

补充 hatch 补充

init(canvas) 后普通用户不必再调这些。

方法 何时用 何时不要用
refresh() 离屏无 canvas，需要 RGBA init(canvas) 后 setOption 已自动上屏
findHover(x, y) 自管命中检测 主路径用 on('mouseover')
handlePointerMove / Leave / Down / Up / Click 离屏或自管指针 init(canvas) 时一般不需要
applyDataZoomWheel(x, deltaY) 自管滚轮 init(canvas) 时滚轮已绑定
getTooltipContent(si, di) 自绘 tooltip（string HTML） init(canvas) 时 facade 已内建 DOM
benchmarkRender(n) 渲染均值耗时（毫秒） 不是官方性能 API；见 bench
hasOption / optionHasFunctions 状态查询 不是官方 API
