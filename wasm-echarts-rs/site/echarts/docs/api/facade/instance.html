实例方法

通过 init() 拿到的 facade 实例。 notMerge 不是 option 字段。

setOption(option, notMerge?, lazyUpdate?) 官方

三种签名。默认同线程同步返回；useWorker 时返回 Promise。

参数 类型 说明
option object 官方形态 option。函数字段仅主线程可用
notMerge boolean | object true 替换整棵树；或 { notMerge, replaceMerge, silent, lazyUpdate }
lazyUpdate boolean 忽略排队，同步 flush

replaceMerge 只按顶层 key 整段替换，不按 component id（降级）。 对照 merge。 

chart.setOption(option);
chart.setOption(option, true);
chart.setOption(option, { notMerge: false, replaceMerge: ['series'] });
await workerChart.setOption(option);

getOption() 官方

已合并 option 转回普通 JSON；函数字段保留为原 Function。Worker 下返回主线程缓存。

const current = chart.getOption();

resize(opts?) 官方

无参读 canvas；resize({ width, height, devicePixelRatio })； 'auto' 回退到 canvas。也接受 native 三位置参数 resize(w, h, dpr)。Worker 下返回 Promise。

参数 类型 说明
opts.width / height number | 'auto' 缺省或 'auto' 读 DOM
opts.devicePixelRatio number 缺省保持当前 dpr 
chart.resize();
chart.resize({ width: 640, height: 400 });

clear() 官方

等价 setOption({ series: [] }, true)。

chart.clear();

showLoading / hideLoading 降级

静态半透明遮罩 + 文案，不播官方旋转动画。

参数 类型 说明
name string | object 官方有多种 Loading；这里忽略类型名。对象则当 cfg
cfg.text string 遮罩文案 
chart.showLoading('default', { text: '加载中' });
chart.hideLoading();

appendData({ seriesIndex, data }) 官方

追加到对应 series.data 后重绘。

chart.appendData({ seriesIndex: 0, data: [8, 9] });

setTheme(theme) 官方

应用已 registerTheme 的名字，或传入主题对象，再按当前 option 重绘。

chart.setTheme('dark');

生命周期与尺寸 官方

方法 说明
isDisposed() 是否已释放
getDom() init 时传入的 canvas；离屏为 null
getId() 实例 id 字符串
getWidth() / getHeight() / getDevicePixelRatio() 离屏位图尺寸
dispose() 释放本实例 
if (!chart.isDisposed()) {
  console.log(chart.getWidth(), chart.getId());
}
