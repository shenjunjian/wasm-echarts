坐标、导出与 getZr

像素换算、把离屏 RGBA 导出成图、以及与 ChartView 共用的 ZRender。

convertToPixel / convertFromPixel 官方

cartesian 多 grid / 多轴 finder（gridIndex / xAxisIndex / yAxisIndex / seriesIndex），含 time / log 轴； 以及 polar / geo / calendar / singleAxis / parallel / matrix / radar finder。

参数 类型 说明
finder string | object 坐标系或 series 定位
value number | number[] 数据值或像素 
const px = chart.convertToPixel({ seriesIndex: 0 }, [0, 120]);
const data = chart.convertFromPixel({ gridIndex: 0 }, [40, 80]);

containPixel(finder, value) 官方

判断像素是否落在对应 grid / polar / geo 等区域内。

chart.containPixel({ gridIndex: 0 }, [80, 80]);

getDataURL / renderToCanvas / getRenderedCanvas 官方

离屏 RGBA → PNG/JPEG 数据 URL，或画到目标 canvas。 getRenderedCanvas 等价 renderToCanvas。

参数 类型 说明
opts.type 'png' | 'jpeg' 'svg' 不支持，只 warn
opts.pixelRatio number 导出倍率
opts.backgroundColor string 导出底色 
const url = chart.getDataURL({ type: 'png' });
const canvas = chart.renderToCanvas();

renderToSVGString / getSvgDataURL 只 warn 并返回空。 getConnectedDataURL 不按 connect 拼图，回退 getDataURL。

getZr() 官方 降级

返回与 ChartView 共用 Storage 的 wasm-zrender ZRender 实例 （同一份 WASM，不是第二份 wasm-zrender/pkg）。 可 add / on / configLayer。

  • 无 SVG painter / hover layer；动画写终态。
  • zr.painter.getSvgDom 只 console.warn。
  • useWorker 时不可用：主线程 warn 并返回 undefined。见 运行模式。
const zr = chart.getZr();
zr.add(new echarts.graphic.Rect({
  shape: { x: 8, y: 8, width: 40, height: 20 },
  style: { fill: '#5470c6' },
}));

refresh() 补充

同步重绘并返回 RGBA。离屏无 canvas、需要自行 putImageData 时用。 init(canvas) 后 setOption 已自动上屏，不必再调。 

const rgba = chart.refresh();
