生命周期

顶层函数：先 await initWasm()，再 init。 有文字时必须先 registerFont。

init(dom, theme?, opts?) 官方 补充

创建图表实例。有 canvas 时 setOption 自动上屏，并绑定 mousemove / click / leave / wheel。 dom 可为 null（离屏；官方客户端无 DOM 会抛错）。

参数 类型 说明
dom HTMLCanvasElement | null 绑 canvas 则指针 + tooltip + 自动 putImageData；null 纯离屏
theme string | object | null 已 registerTheme 的名字，或主题对象。首次 setOption 当默认项合并
opts.width / height number 缺省读 canvas 位图 / clientWidth；再缺省 300×150
opts.devicePixelRatio / dpr number 默认 1
opts.useWorker 补充 boolean 默认 false。详见 运行模式 
const chart = init(canvas);
const offscreen = init(null, null, { width: 480, height: 360 });
const worker = init(canvas, null, { useWorker: true });

对照 line、 bar-large。

dispose(chart | canvas | id) 官方

释放单个实例（也可用 chart.dispose()）。按实例、canvas 或 id 查找。

参数 类型 说明
chart facade 实例 / canvas / id 字符串 已 dispose 的忽略 
dispose(chart);
dispose(canvas);
chart.dispose();

getInstanceByDom / getInstanceById 官方

按 canvas 或实例 id 取回已包装的 facade。

参数 类型 说明
dom canvas getInstanceByDom
id string chart.getId() 
const again = getInstanceByDom(canvas);
const byId = getInstanceById(chart.getId());

version 官方

字符串常量 '6.1.0'，对齐官方 ECharts 版本号。

import { version } from '@wasm-echarts';
console.log(version); // '6.1.0'

use(...) 降级

导出且签名对齐；只 console.info，不按需加载。 已开发的图表 / 组件都编进 WASM，不必 echarts.use(BarChart)。 

import { use } from '@wasm-echarts';
use(); // 只打印提示

registerFont / clearFonts 补充

向本模块全局 fontdb 注入 / 清空字体。完整规则见 字体引用。 

registerFont(bytes, {
  familyName: 'Noto Sans SC',
  sansSerif: ['Noto Sans SC'],
});
