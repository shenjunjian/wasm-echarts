EChartsInstance

wasm-bindgen 内部 handle（src/instance.rs）。 facade 用 camelCase 包装同一套能力。不要直接 new。

对照表

pkg / native facade 说明
new EChartsInstance(w, h, dpr) init(...) 创建 ZRenderer 并登记进 ZR_REGISTRY
set_option(option, opts?) setOption opts 为 { notMerge, replaceMerge }
get_option() getOption 函数字段保留
resize(w, h, dpr) resize facade 还读 canvas / 'auto'
refresh() refresh 返回 RGBA 补充
getZr() getZr() 同一 id 的 zrender handle；facade 再包一层 JS 类
attachHost(dom) （内部） 把 canvas 绑到 zrender Handler
width() / height() / dpr() getWidth / getHeight / getDevicePixelRatio 尺寸
find_hover(x, y) findHover 补充
handle_pointer_move / leave / handlePointerDown / Up / Click handlePointer* 补充；facade 在有 canvas 时自动调
apply_data_zoom_wheel applyDataZoomWheel 补充
get_tooltip_content getTooltipContent 补充
dispatch_action dispatchAction 已接线 type 见事件页
appendData / containPixel 同名 追加数据；像素包含
convert_to_pixel / convert_from_pixel convertToPixel / convertFromPixel 坐标换算
update_font_database （内部，registerFont 后调） 热更新 fontdb
has_option / option_has_functions hasOption / optionHasFunctions 补充
benchmark_render(n) benchmarkRender 补充
dispose() dispose 从 registry 卸 Zr 
// 调试才碰 handle
const handle = new EChartsInstance(480, 360, 1);
handle.set_option({
  xAxis: { type: 'category', data: ['A'] },
  yAxis: { type: 'value' },
  series: [{ type: 'bar', data: [1] }],
});
const rgba = handle.refresh();
