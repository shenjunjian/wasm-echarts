不要直接用的符号

pkg 为了对齐 wasm-bindgen 与 zrender 图元表，会导出一批业务不该碰的符号。 有内容的公开 API 在 JS facade。

@wasm-echarts 也再导出了 EChartsInstance，那是给内部 / 调试看的。 业务请用 init()。

不要直接构造 仅 pkg

符号 请改用
new EChartsInstance(width, height, dpr) init(canvas | null, theme?, opts?)
attachHost(dom) facade 在 init(canvas) 时内部绑定
registerCustomSeriesType(type) registerCustomSeries(type, renderItem)
pkg 顶层 registerTransform / registerMap / parseGeoJSON 同名 facade 导出（会同步 Worker、包装 upstream）

随包再导出的 zrender 类

echarts 的 .wasm 编进了 wasm-zrender 的图元绑定（Rect / Group / LinearGradient 等），供 getZr 与 graphic 使用。从 pkg 直接 new Rect 没有 JS 原型链。 请用 import { graphic } from '@wasm-echarts'，或 zrender 文档站的 @wasm-zrender（那是另一份 wasm，echarts 页不要加载）。

仅 Rust、JS 看不到

insert_renderer / attach_host / with_zr 等 crate 函数没有 #[wasm_bindgen]，pkg 里没有这些名字。 ChartView 用它们把系列图画进同一份 ZRenderer。
