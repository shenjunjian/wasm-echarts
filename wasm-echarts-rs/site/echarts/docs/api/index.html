API 参考

默认走 JS facade（@wasm-echarts）。 pkg/ 是 wasm-bindgen handle，单独成章。

两层入口

层 导入 给谁用
JS facade import initWasm, { init } from '@wasm-echarts' 业务代码。官方 init / setOption / on。
pkg 导出 不要从业务直接 import '../pkg/wasm_echarts.js' 调试，或绕过 facade 包装。不要 new EChartsInstance。

每条 API 带徽章：官方 对齐官方 core.ts / export/api.ts； 补充 是 wasm-echarts 多出来的； 降级 签名在、语义弱于官方。

JS facade 分页

  • 总览与约定 — 导入、initWasm vs 命名导出、useWorker 只在 init 的 opts
  • 生命周期 — init / dispose / use / registerFont
  • 实例方法 — setOption / resize / Loading
  • 事件与 dispatchAction — on / off / 已接线 action
  • 坐标、导出与 getZr — convertToPixel / getDataURL / getZr
  • 命名空间与扩展 — graphic / registerMap / hatch

pkg 导出分页

  • 总览与何时使用 — 业务走 facade；pkg 给调试
  • EChartsInstance — native 方法与 facade camelCase 对照
  • 不要直接用的符号 — 不要 new、空壳与仅 pkg
