未实现

下列官方入口已导出同名，内部只 console.warn： registerLocale、convertToLayout、getVisual、 renderToSVGString、getSvgDataURL、getModel。 getConnectedDataURL 不按 connect 拼图，回退 getDataURL。 isSSR() 恒为 false。updateLabelLayout 为空操作。

缺口 说明
图表简化 未识别的 series.type 会 warn。force 不迭代、桑基非完整节点平衡、tree 非 tidy、chord 用贝塞尔而非丝带、pictorialBar 非全部 symbolClip
缺增量绘制 bar / candlestick 无增量 large：几十万点会在 WASM 里一次画完。画廊大数据例开 useWorker 只保证主线程还能响应，Worker 内仍是长任务。见 运行模式
parallel 无 progressive 每条数据一条 Path；上万行同样是同步长任务
大树 treemap 过深 / 过大的树在递归 parse / squarify 时会 WASM panic。库现在画不了这类数据
treemap levels 色映射 series.levels.color + visualDimension 未按官方做，渲染会 panic
缺外部插件 官网回归 / 聚类示例依赖全局 ecStat（echarts-stat）；热力 / 散点百度地图示例依赖 bmap。本宿主都不注入
组件 geo roam / SVG 地图源。toolbox DataView DOM / SaveAsImage 下载条明确不做
option 名字在但未按官方做 smoothMonotone、pie 完整 avoidLabelOverlap / padAngle / alignTo、bar showBackground / polar roundCap、色板不是官方 palette 全套、rich text 当普通 Text
tooltip HTMLElement formatter / confine / renderMode: 'richText'
UniversalTransition 只跳终态，不做系列间插值

未实现的官方方法仍导出同名 + console.warn，避免 is not a function。
