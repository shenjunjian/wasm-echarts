允许例外 降级

仓库目标是一帧终态图像，这些是刻意取舍，不是以后再补的缺口。

例外 官方 wasm-echarts
字体 浏览器字体引擎 必须从 @wasm-echarts registerFont。见 字体引用
动画 rAF 播中间帧 setOption / animation / universalTransition 直接终态。无系列间插值
离屏 DOM canvas / SVG painter / hover layer 仅 canvas 离屏。无 SVG / hover 层。WASM 不操作页面 2D context
宿主 客户端 init 需要 DOM init(canvas) 绑指针并自动上屏；init(null, null, { width, height }) 纯离屏
use(...) 按需加载图表 / 组件 不加载模块，只 console.info：已开发的都编进 WASM
Loading 旋转动画 静态半透明遮罩 + 文案
DataView / SaveAsImage toolbox DOM 浮层 / 下载条 明确不做

已对齐 官方

可按官方文档调用。细节与参数表在 JS facade API。

补充 API 补充

wasm-echarts 多出来的。不要当成浏览器 ECharts 的官方方法来用。

API 用途 何时不该当官方用
