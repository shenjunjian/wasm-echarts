wasm-zrender 实例

wasm-zrender 文档

对齐官方 zrender export.ts 的 WASM 命名空间导出，底层封装 rust_zrender::ZRenderer。

快速开始

cd crates/wasm-zrender && wasm-pack build --target web

cd ../../site && npm install && npm run dev
# 打开 http://127.0.0.1:5173/zrender/examples/

顶层 API

  • init(dom?, opts?) — 创建 ZRender。传入 HTMLCanvasElement（或含 canvas 的容器）时绑定 Handler：zr.on / el.on / draggable 生效，并自动 putImageData。无 DOM 时尺寸来自 opts，可用 zr.handler.dispatch 注入事件
  • registerFont(data, opts?) — 注册字体 bytes 到全局 fontdb（Text 渲染前必调，见下节）
  • clearFonts() — 清空已注册字体（测试用）
  • dispose(zr) / disposeAll() — 释放实例
  • getInstance(id) — 按 id 取实例

字体加载（Text 必看）

wasm-zrender 在 Rust 离屏 Canvas（vl-convert-canvas2d + cosmic-text）中绘制文本， 不经过浏览器 ctx.font。WASM / Wasmer 等宿主读不到操作系统字体， 因此 不会 在 .wasm 内嵌入默认字体，而由宿主在运行时注入。

使用 Text 图元或任何含文字的渲染前，须先注册至少一种字体；否则 refresh() 会报错 no default font found。

调用顺序

  1. await initWasm()
  2. registerFont(bytes, opts?) — 加载 TTF / OTF / WOFF 文件内容
  3. init(...) → 构图 → refresh()

可在任意时刻再次调用 registerFont；已创建的 ZRender 实例会自动热更新 fontdb。

registerFont(data, opts?)

  • data — Uint8Array，字体文件原始 bytes
  • opts.familyName — 可选，覆盖字体族名（不传则读字体 name table）
  • opts.sansSerif — 可选，string[]，将 CSS sans-serif 映射到这些族名；若只传 familyName 则默认映射到该族名
import initWasm, { init, registerFont, Text } from '@wasm-zrender';

await initWasm();

const bytes = new Uint8Array(
  await (await fetch('/fonts/NotoSansSC-Regular.ttf')).arrayBuffer()
);
registerFont(bytes, {
  familyName: 'Noto Sans SC',
  sansSerif: ['Noto Sans SC'],
});

const zr = init(null, { width: 480, height: 360, devicePixelRatio: dpr });

zr.add(new Text({
  style: {
    text: 'wasm-zrender 文本',
    x: 24,
    y: 48,
    fill: '#333',
    fontSize: 18,
  },
}));

const rgba = zr.refresh();
const ctx = canvas.getContext('2d');
ctx.putImageData(new ImageData(new Uint8ClampedArray(rgba), zr.width(), zr.height()), 0, 0);

site 薄壳辅助

文档站提供 site/src/zrender/fonts.js： loadFontFromUrl(url)、ensureDefaultFont()、registerFontBytes(bytes)。 默认字体文件：site/public/fonts/NotoSansSC-Regular.ttf。 text 示例（text.js）内联演示完整流程。

Wasmer / 原生 Rust 宿主

use rust_zrender::{register_font, RegisterFontOptions, ZRenderer};

register_font(font_bytes, RegisterFontOptions {
    family_name: Some("Noto Sans SC".into()),
    sans_serif: Some(vec!["Noto Sans SC".into()]),
})?;

let mut zr = ZRenderer::new(480, 360)?;

wasm32 目标不加载系统字体；原生目标默认仍加载系统字体，并与已注册字体合并。

ZRender 实例方法

  • add(el) / remove(el) / clear() — 根节点增删与清空
  • refresh() / flush() — 同步返回 RGBA 字节数组
  • resize(opts) — 调整尺寸（不重载预设场景）
  • findHover(x, y) — 返回 { target, topTarget }
  • getWidth() / getHeight() — 逻辑宽高（同 width() / height()）
  • on(event, handler) / off(event, handler?) / trigger(event) — 实例事件；animation.on('frame') 为空操作（无帧循环）
  • setBackgroundColor(color) / getBackgroundColor() — 背景色
  • setCursorStyle(cursor) — 默认光标（有 canvas 时写 style.cursor）
  • configLayer(zlevel, config) — 无图层配置，触发 refresh
  • dispose() — 释放本实例

已实现图元与几何

图元：Group、Rect、Circle、Line、Polygon、 Polyline、Sector、Text、TSpan、Image、 Path、CompoundPath、Displayable，以及 Arc、Ellipse、Ring、BezierCurve、 Heart、Star、Isogon、Droplet、Rose、Trochoid 等 Path 子类。

样式：LinearGradient、RadialGradient、Pattern。

几何值对象（不参与 Storage）：Point、BoundingRect、OrientedBoundingRect。

图元原型链：Rect instanceof Path instanceof Displayable instanceof Element（Group 亦 instanceof Element）。 变换主属性：x / y / scaleX / scaleY / rotation / originX / originY。 attr / setShape / setStyle 支持对象与 key, value。

Path 子类支持 useState / useStates / getState / ensureState / clearStates、setStateStyle、setClipPath / getClipPath / removeClipPath、getBoundingRect、position。 hide / show / on / off / trigger。 Path.extend({ buildPath }) 把命令录成 shape.pathData。 IncrementalDisplayable 按普通 Group 语义可构造（非增量图层）。 animate().when().start() 立刻写入最后一组目标属性。

工具模块

matrix、vector、color、path（createFromString → Path + pathData）、util 按官方签名实现。 morph.morphPath 直接返回终点 path；parseSVG 解析 g / path / 基础图形； showDebugDirtyRect 为空操作（无 dirty rect）。

与官方 zrender 的差异（仅此四条例外）

  • 字体：必须 registerFont / register_font，WASM 不读系统字体
  • 动画：不播中间帧；animate / animateTo / when().start() 立刻写入最后一组目标属性
  • 离屏：仅 canvas；refresh() / flush() 同步返回 RGBA；无 SVG painter / hover layer / dirty rect
  • 宿主：init(canvas) 可自动 putImageData；init(null) 仍用 opts 宽高

本波不挡主路径（后置，不混进「已对齐」）：skewX/Y anchorX/Y、 textContent 自动布局、RichText、morph 形变、 IncrementalDisplayable 增量语义、Path.extend 自定义 buildPath 走完整 PathProxy。

架构关系

wasm-zrender 与 wasm-echarts 为 sibling，均只依赖 rust-zrender。 echarts 图表管线不经过 wasm-zrender，而是内部直接使用 ZRenderer。
