快速上手

从 @wasm-zrender（js/ facade）导入，先加载 WASM，再构图。 pkg/ 是 wasm-bindgen 胶水，不是业务公开面。

pkg 与 JS facade

wasm-pack build --target web 产出 crates/wasm-zrender/pkg/ （wasm_zrender.js + .wasm）。这是内部 handle：无原型链，工具模块多为空对象。

公开入口是 crates/wasm-zrender/js/index.js。它包装 native handle，补上 Rect instanceof Path instanceof Displayable instanceof Element， 以及 matrix / vector / color 等工具命名空间。 文档站 Vite alias @wasm-zrender 指向这份 js/。

业务 / site → js/index.js → pkg/ → rust-zrender → RGBA

默认导出是 wasm-bindgen 的 initWasm；命名导出才是 zrender API。 不要直接 import pkg/wasm_zrender.js。

编译与启动

cd crates/wasm-zrender && wasm-pack build --target web

cd ../../site && npm install && npm run dev
# 打开 http://127.0.0.1:5173/zrender/examples/

改 Rust 引擎后必须重新 wasm-pack，浏览器才能拿到新逻辑。 更完整的构图见 实例画廊。 仓库定位与三层分工见 站点首页。

推荐调用顺序

  1. await initWasm() — 加载 .wasm
  2. 有文字时 registerFont(bytes, opts?)（详见 字体引用）
  3. init(canvas | 含 canvas 的容器 | null, opts?)
  4. zr.add 图元
宿主 行为
init(canvas) 绑定指针；add / attr / 非 mousemove 事件后自动 putImageData
init(null, { width, height }) 纯离屏。尺寸只来自 opts（默认 300×150，dpr 默认 1）；refresh() 返回 RGBA

绑了 canvas 时，请把 canvas.width / canvas.height 设成与 opts 一致； 上屏不会改位图尺寸。无 DOM 时用 zr.handler.dispatch 注入事件。

示例：绑定 canvas

传入 HTMLCanvasElement（或内部含 canvas 的容器）后， add 会自动把离屏 RGBA 贴上屏，不必手写 putImageData。 可对照 Bounding Box。 

import initWasm, { init, Rect } from '@wasm-zrender';

await initWasm();

const canvas = document.getElementById('canvas');
canvas.width = 480;
canvas.height = 360;

const zr = init(canvas, { width: 480, height: 360 });
zr.add(new Rect({
  shape: { x: 24, y: 24, width: 160, height: 80 },
  style: { fill: '#5470c6' },
}));

示例：纯离屏

init(null) 不绑 DOM，refresh() / flush() 同步返回 RGBA 字节数组。 可对照 Hello World。 

import initWasm, { init, Circle } from '@wasm-zrender';

await initWasm();

const zr = init(null, { width: 480, height: 360 });
zr.add(new Circle({
  shape: { cx: 80, cy: 80, r: 40 },
  style: { fill: '#91cc75' },
}));

const rgba = zr.refresh();
const ctx = canvas.getContext('2d');
ctx.putImageData(
  new ImageData(new Uint8ClampedArray(rgba), zr.width(), zr.height()),
  0,
  0,
);
