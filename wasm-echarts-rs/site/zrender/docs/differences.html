与官方差异

公开表面对齐官方 export.ts / zrender.ts / Element.ts。 做不到的不改名糊弄：例外、未实现、补充分表列出。

允许例外只有四条。 skewX、textContent、morph 形变、增量图层等是后置未做， 不要写成「本仓库允许不一致」。徽章含义见侧栏。

允许例外 降级

仓库目标是一帧终态图像，这四条是刻意取舍，不是以后再补的缺口。

例外 官方 wasm-zrender
字体 ctx.font 走系统 / 网页字体 必须 registerFont。未注册含 Text 的 refresh 会 no default font found。见 字体引用
动画 rAF 播中间帧 animate / animateTo / when().start() 立刻写入最后一组目标。见 动画与事件
离屏 DOM canvas / SVG painter / hover layer / dirty rect 仅 canvas 离屏。WASM 不操作 DOM 2D context；refresh / flush 同步返回 RGBA。无 SVG、无 hover 层、无脏矩形
宿主 客户端 init 需要 DOM init(canvas) 绑指针并自动 putImageData；init(null, { width, height }) 纯离屏，尺寸只来自 opts。无 DOM 时用 zr.handler.dispatch

已对齐 官方

可按官方文档调用。细节与参数表在 JS facade API。

降级 / 后置（未实现） 降级

后置 = 还没做，不要写进「已对齐」。 降级 = 签名在，语义弱于官方。两者都不是允许例外。

条目 类别 现状

补充 API 补充

wasm-zrender 多出来的，或同名但语义多了一截。不要当成浏览器 zrender 的官方方法来用。

API 用途 何时不该当官方用
registerFont / clearFonts 向全局 fontdb 注入 / 清空字体 bytes；会热更新已有实例 官方没有这两项。业务必须自己 fetch 字体
refresh() / flush() 返回 RGBA 同步重绘，返回 Uint8Array 像素 官方是 void。绑了 canvas 时多数变更会自动 putImageData，不必每次手写回图
init(null, { width, height }) 纯离屏，不绑 DOM 官方客户端无 DOM 会抛错。尺寸只来自 opts（默认 300×150，dpr 默认 1）
Pattern.imageData / imageWidth / imageHeight 裸 RGBA + 尺寸；Uint8Array 必带宽高 官方 Pattern 吃 Image / Canvas。URL 未 decode 时同步路径失败
zr.width() / height() / dpr() 读离屏位图尺寸 官方用 getWidth / getHeight（这里也有）。简写是 hatch
zr.handler.dispatch 无 DOM 时注入指针事件（zrX / zrY） 签名是官方 Handler 的；在本仓库里主要服务 init(null) 与测试，不要指望 hover layer 
import initWasm, { init, registerFont, Rect } from '@wasm-zrender';

await initWasm();
registerFont(fontBytes, { familyName: 'Noto Sans SC' });

const zr = init(null, { width: 480, height: 360 });
zr.add(new Rect({
  shape: { x: 8, y: 8, width: 80, height: 40 },
  style: { fill: '#5470c6' },
}));
const rgba = zr.refresh(); // 补充：官方 refresh 不返回像素
