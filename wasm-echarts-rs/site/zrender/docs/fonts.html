字体引用

浏览器能画字，是因为 ctx.font 走系统 / 网页字体引擎。 WASM 读不到操作系统字体，Text 渲染前必须 registerFont。

这是允许例外，不是可省略步骤。未注册任何字体时，含 Text 的 refresh() 会报 no default font found。

为什么 Chrome 能画、WASM 不能

官方 zrender 把文字交给浏览器 Canvas2D：ctx.font = '18px sans-serif' 由 Chrome 解析族名，再从系统字体或 @font-face 取字形。

wasm-zrender 在 Rust 离屏 Canvas（vl-convert-canvas2d + cosmic-text）里 fillText，不经过浏览器 ctx.font。WASM / Wasmer 等宿主 读不到 OS 字体，仓库也禁止把默认 TTF 打进 .wasm，因此必须由宿主在运行时注入字体 bytes。

调用顺序

  1. await initWasm()
  2. registerFont(bytes, opts?) — 加载 TTF / OTF / WOFF（TTC 须带 familyName）
  3. init(...) → 构图 → 上屏或 refresh()

可在任意时刻再次调用 registerFont。全局 fontdb 会同步到 已创建的 ZRender 实例（热更新）；再 add / refresh 即可用新字体画字。

registerFont(data, opts?) 补充

参数 类型 说明
data Uint8Array 字体文件原始 bytes
opts.familyName string? 覆盖字体族名。不传则读字体 name table
opts.sansSerif string[]? 把 CSS sans-serif 映射到这些族名（按优先级）

clearFonts() 清空已注册字体，主要用于测试；同样会热更新已有实例。

sans-serif 映射

  • 显式传 sansSerif：覆盖当前映射
  • 只传 familyName、且尚无映射：默认映射到该族名
  • 后续再注册其它字体且不传 sansSerif：不覆盖已有映射

Text.style.fontFamily

会拼进离屏 canvas 的 setFont（例如 18px "Microsoft YaHei"）。 不设则用 sans-serif，因此依赖上面的映射。 当前解析的文本样式字段是 fill / fontSize / fontFamily / textAlign / textBaseline。 

import initWasm, { init, registerFont, Text } from '@wasm-zrender';

await initWasm();

const bytes = new Uint8Array(
  await (await fetch('/fonts/NotoSansSC-Regular.ttf')).arrayBuffer()
);
registerFont(bytes, {
  familyName: 'Noto Sans SC',
  sansSerif: ['Noto Sans SC'],
});

const zr = init(canvas, { width: 480, height: 360 });
zr.add(new Text({
  style: {
    text: 'wasm-zrender 文本',
    x: 24,
    y: 48,
    fill: '#333',
    fontSize: 18,
    fontFamily: 'Noto Sans SC',
  },
}));

完整流程见 text 示例。

site 辅助，不是库 API

文档站提供 site/src/zrender/fonts.js，方便示例少写 fetch：

  • loadFontFromUrl(url, opts?)
  • ensureDefaultFont() — 拉取 /fonts/NotoSansSC-Regular.ttf
  • registerFontBytes(bytes, opts?)

业务项目应自己 fetch 字体再调 facade 的 registerFont。 wasm-echarts 另有一份 fontdb，须从 @wasm-echarts 单独注册，两边不共享。

Wasmer / 原生 Rust

use rust_zrender::{register_font, RegisterFontOptions, ZRenderer};

register_font(font_bytes, RegisterFontOptions {
    family_name: Some("Noto Sans SC".into()),
    sans_serif: Some(vec!["Noto Sans SC".into()]),
})?;

let mut zr = ZRenderer::new(480, 360)?;

wasm32 目标 load_system_fonts = false； 原生目标默认仍加载系统字体，并与已注册字体合并。
