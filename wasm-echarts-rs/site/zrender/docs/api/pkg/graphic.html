图元与样式类

pkg 图元是独立 wasm 类，没有 JS 原型链。 shape / style 字段与 facade 相同（解析在 bridge/shape.rs / opts.rs），读写方式不同。

不要读 handle.x / handle.style.fill：pkg 没有这些 getter。 改属性用 attr / setShape / setStyle / position。字段表见 facade 图元、 样式与几何。

Element 仅 pkg

薄 handle：只有 id 与 type。没有 constructor，不能 new Element()。findHover 的 target 就是它。facade 的 Element 是完整 JS 基类。

成员 类型 说明
id number 元素表 id
type string 如 'rect'；找不到则 'unknown' 
const hit = zr.findHover(10, 10);
hit.target.id;
hit.target.type; // 'rect'

Path / Shape 公共方法 官方

Path 与各 Shape（Rect、Circle 等）方法表相同。 构造：new Xxx(opts)，opts 与 facade 相同。 attr / on / setShape 等返回新 handle（同一 id），不是同一个对象。

方法 参数 说明
attr(key, value) / attr(obj) 字符串键或对象 认 position / shape / style / 变换 / z / clipPath 等
setShape(shape) / setStyle(style) 对象 patch 合并进 pending 与 storage
position [x, y] 唯一成对的变换 getter/setter；没有 x / scaleX 独立 getter
useState / useStates / setStateStyle 状态名 / 名数组 / 样式 Path 与 Shape 有；Text / Image 没有单独导出
setClipPath / removeClipPath clip 图元 clip 必须是 Path 才能进 storage
getBoundingRect() — 返回 pkg BoundingRect
animate(path, looping) 降级 'shape' / 'style' / 空 返回 pkg Animator（终态）。facade 用的是 JS Animator
on / off / trigger 事件名 + 函数 与实例级相同
hide / show — 写 ignore
draggable boolean | 'horizontal' | 'vertical' getter/setter 
const rect = new Rect({
  shape: { x: 8, y: 8, width: 80, height: 40 },
  style: { fill: '#5470c6' },
});
rect.setShape({ width: 120 });
rect.position = [24, 16];
rect.attr('rotation', Math.PI / 8);

type 字符串（register_path 的第一参）如下。shape 字段见 facade 图元页。

类 type 类 type
Path path Rect rect

Line line Polyline / Polygon 同名
Sector / Arc / Ring 同名 BezierCurve bezier-curve

Path.extend 不在 pkg。仅 facade

Group 官方

new Group() 不接收 opts（facade 会 attr(opts)）。 子节点 API 只有挂载侧；遍历在 JS 数组上，pkg 没有。

方法 pkg facade
add / remove / replace / addBefore / removeAll 有（成功返回 undefined） 有（返回 this，并维护 _children）
children / childAt / childOfName / eachChild / traverse 无 仅 facade
animate / attr / clip / position 有 有 
const g = new Group();
g.add(new Circle({ shape: { cx: 40, cy: 40, r: 16 } }));
g.attr({ x: 10, y: 10 });

Text / Image / TSpan 官方

类 type 差异
Text text 有 setStyle；构造不抛错。有文字必须先 registerFont
Image image 构造可能失败（图未 decode）。没有单独的 setStyle，走 attr
TSpan tspan 单 run 文本，与 Text 共用 Storage；方法比 Text 更少 
const t = new Text({
  style: { text: 'hello', fontSize: 16, fill: '#000' },
  x: 8,
  y: 24,
});
t.setStyle({ text: 'hi' });

对照 text、image。

渐变与 Pattern

facade 从 native 再导出，所以 LinearGradient / RadialGradient / Pattern 就是 pkg 类。

类 构造 说明
LinearGradient 官方 (x, y, x2, y2, colorStops?, global?) NaN 时 x/y=0、x2=1、y2=0。有 addColorStop
RadialGradient 官方 (x, y, r, colorStops?, global?, r0?) 默认中心 0.5、r=0.5；r0 可写
Pattern 补充 (image, repeat?) 另有 imageData / imageWidth / imageHeight 
const lg = new LinearGradient(0, 0, 1, 0, [
  { offset: 0, color: '#5470c6' },
  { offset: 1, color: '#91cc75' },
]);
rect.setStyle({ fill: lg });

Point / BoundingRect / OrientedBoundingRect

值对象，实例方法大体对齐官方。静态方法有分叉：

符号 pkg facade
Point.set / copy / lerp 等静态 无 JS 挂到类上。仅 facade
BoundingRect.calculateTransform 实例方法：rect.calculateTransform(other) → number[] 静态：BoundingRect.calculateTransform(out, a, b)，签名不同
BoundingRect.create / set 静态，写纯对象 {x,y,width,height} 未再包一层；用 pkg 的即可 
const a = new BoundingRect(0, 0, 10, 20);
const b = new BoundingRect(0, 0, 20, 40);
const m = a.calculateTransform(b); // pkg：6 个数的数组
a.contain(4, 4); // true

pkg Animator 降级

el.animate() 返回 wasm Animator：when 只留最后一组， start 立刻写终态，再 during(undefined, 1) 与 done。 facade 自己实现了一份 JS Animator（during(target, 1)），不要混用两套。 

rect.animate('shape').when(400, { width: 200 }).start();
