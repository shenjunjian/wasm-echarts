空壳与不要直接用的符号

pkg 为了对齐官方 export.ts 的符号表，会导出一批空对象、空函数，以及构造即抛错的类。 有内容的实现在 JS facade。

matrix() / vector() / color() 等返回的是 {}，不是命名空间。从 pkg 调 matrix.create 会是 undefined。用 import { matrix } from '@wasm-zrender'。

空壳 tool 仅 pkg 降级

源码 src/export.rs：每个函数 Object::new()，避免 wasm-bindgen 缺符号。

pkg 导出 返回 请改用
matrix() 空对象 facade matrix（js/tool/matrix.js）
vector() 空对象 vector
color() 空对象 color
path() 空对象 path
util() 空对象 util
morph() 空对象 facade morph 仍是降级 stub
parseSVG() 空对象 facade parseSVG 仍是降级 stub 
import { matrix } from '@wasm-zrender';
const m = matrix.create(); // OK

import { matrix as pkgMatrix } from '../../../pkg/wasm_zrender.js';
pkgMatrix();          // {}
pkgMatrix.create;     // undefined

完整签名见 工具模块。

空操作函数 降级

函数 行为
showDebugDirtyRect() no-op。无 dirty rect 可视化
setPlatformAPI(api) 忽略参数。不切换平台实现 
showDebugDirtyRect();
setPlatformAPI({});

构造即抛错的类

类 pkg facade
Displayable new Displayable() 抛「抽象基类，用 Rect / Circle / Text / Image / Group」 可 new Displayable() 作原型祖先，不建 native
IncrementalDisplayable 降级 抛 IncrementalDisplayable is not implemented 绑 native.Group()，当普通 Group 用，无增量图层 
new Displayable();              // pkg：抛错
new IncrementalDisplayable();   // pkg：抛错
// facade：
new IncrementalDisplayable();   // 可用，type === 'incremental'

同名但不要当 facade 用

符号 为什么不要直接用
pkg Element 几乎只有 id / type。没有变换、事件、attr
pkg Group 无 children / traverse；构造不收 opts
pkg Animator during 的第一个参数是 undefined，与 JS Animator 不同
pkg ZRender.add 不返回 this；也没有 painter
HoverResult.target 是薄 Element，不是带 style 的 JS 图元

JS 有、pkg 没有 仅 facade

  • version、registerPainter、zr.painter
  • Path.extend
  • Group：children / childAt / childOfName / eachChild / traverse / childCount
  • Element 状态机：ensureState / getState / clearStates / toggleState 等（pkg Path 只有 useState / useStates / setStateStyle）
  • Point.set / lerp 等静态方法
  • 独立的 x / y / scaleX / style / shape JS 属性

Rust crate 有、JS pkg 没有 仅 pkg

这些是 pub fn，没有 #[wasm_bindgen]， 浏览器 import 不到。wasm-echarts 在 Rust 里调用，把同一份 ZRenderer 挂进 zrender 注册表。

函数 给谁用
insert_renderer / dispose_renderer echarts init 把内部 ZRenderer 登记成 zr id
attach_host(zr_id, dom) init(canvas) 后绑定指针，供 getZr().on
with_zr 在已有实例上刷新 / 命中 / 改背景
rematerialize_mounted_roots echarts 重绘时把 JS 侧图元再写进 storage

不要在页面里找这些名字。原理见 底层原理。
