顶层函数与 ZRender

源码 src/zrender.rs / font.rs / handler.rs。 与 facade 同名，但返回的是 wasm handle，不是包装后的 JS 实例。

init(dom, opts) 官方 补充

创建离屏 ZRenderer，登记 id，再 handler::attach。 尺寸只来自 opts（不读 DOM CSS）。dom 可为 canvas、内含 canvas 的容器，或 null / undefined（离屏）。

参数 类型 说明
dom HTMLCanvasElement | HTMLElement | null 绑 canvas 则指针事件 + 自动 putImageData
opts.width number 默认 300；必须 > 0
opts.height number 默认 150；必须 > 0
opts.dpr / devicePixelRatio number 默认 1

与 facade 不同：返回裸 ZRender handle，没有 painter、dom 缓存，也不进 facade 的实例 Map。 业务应调 facade 的 init，见 生命周期。 

const zr = init(canvas, { width: 480, height: 360, dpr: 1 });
zr.id; // number
const offscreen = init(null, { width: 480, height: 360 });

dispose / disposeAll / getInstance 官方

函数 参数 说明
dispose(zr) pkg ZRender 按 zr.id 从注册表删除。也可用 zr.dispose()
disposeAll() — 解绑全部指针，清空实例表与元素表
getInstance(id) number 存在则 ZRender.from_id；否则 undefined

facade 的 getInstance 会包一层并走 JS 缓存；pkg 每次都是新的 handle 对象（同一 id）。 

const again = getInstance(zr.id);
dispose(zr);
disposeAll();

registerFont / clearFonts 补充

与 facade 同一套 wasm 函数。未注册字体时含 Text 的 refresh 会 no default font found。规则见 字体引用。

参数 类型 说明
data Uint8Array TTF / OTF / WOFF bytes
opts.familyName string? 覆盖族名
opts.sansSerif string[]? 把 CSS sans-serif 映射到这些族名 
registerFont(bytes, { familyName: 'Noto Sans SC', sansSerif: ['Noto Sans SC'] });
clearFonts();

facade 有、pkg 没有

符号 说明
version JS 常量 '6.1.0'。仅 facade
registerPainter 只记进 JS Map，不切后端。仅 facade
zr.painter JS 占位对象。仅 facade

add / remove / clear 官方

用 el.id 在元素表里解析（facade 图元也能传，因为有 id）。 有 DOM 时随后 paint_if_bound。

方法 参数 返回
add(el) 任意带有效 id 的图元 undefined（facade 返回 this）
remove(el) 已挂上的图元 同上
clear() — 清空本实例图元 
zr.add(new Rect({ shape: { x: 8, y: 8, width: 80, height: 40 } }));
zr.remove(rect);
zr.clear();

refresh() / flush() 官方 补充

官方返回 void。这里同步离屏绘制并返回 RGBA （Uint8Array，长度 width × height × 4）。 flush 直接调 refresh。 

const rgba = zr.refresh();
ctx.putImageData(
  new ImageData(new Uint8ClampedArray(rgba), zr.width(), zr.height()),
  0, 0,
);

尺寸 / resize / 背景 / 光标 补充

成员 说明
width() height() dpr() 简写；官方常用 getWidth() / getHeight()（同样导出）
resize(opts) 按 width / height / dpr 重建离屏缓冲；规则与 init 相同
setBackgroundColor(color) CSS 字符串；null / undefined 清掉。有 DOM 立刻上屏
getBackgroundColor() 字符串或 undefined
setCursorStyle(cursorStyle) 有 canvas 时写 style.cursor；空值当 'default'
configLayer(zLevel, config) 降级 忽略参数，只 paint_if_bound 
zr.resize({ width: 640, height: 400, dpr: 2 });
zr.setBackgroundColor('#f5f5f5');
zr.setCursorStyle('pointer');

findHover(x, y) 官方

kurbo 命中，不靠 isPointInPath。未命中返回 undefined。 返回 HoverResult：target / topTarget 是 pkg Element（几乎只有 id / type），不是 facade 包装。

参数 / 返回 类型 说明
x y number 逻辑坐标
返回 { target, topTarget } pkg HoverResult 
const hit = zr.findHover(40, 40);
if (hit) console.log(hit.target.id, hit.target.type);

对照 hit 示例（示例走 facade）。

on / off / trigger 官方

把 js_sys::Function 存进 handler registry。 返回新的 ZRender handle（同一 id），不是同一个 JS 对象。 facade 则返回包装后的 this。

方法 参数 说明
on(event, handler) string, Function 非函数则忽略
off(event?, handler?) 事件名 / handler 均可省略 不传 handler 则清该事件全部监听
trigger(event, packet?) string, 任意 手动派发 
zr.on('click', (e) => console.log(e.target));
zr.off('click');

handler / animation / id / dispose

成员 说明
id 实例数字 id
handler.dispatch(name, event) 补充 无 DOM 时注入指针。读 zrX/zrY 或 offsetX/offsetY
handler.setCursorStyle 与实例方法相同
animation.on/off 降级 空操作；无帧循环
dispose() 从实例表删除并释放 
zr.handler.dispatch('mousedown', { zrX: 40, zrY: 40 });
