生命周期

顶层函数：先 await initWasm()，再 init。 有文字时必须先 registerFont。

init(dom?, opts?) 官方 补充

创建 ZRender 实例。尺寸只来自 opts（不读 DOM 的 CSS 宽高）。 dom 可为 canvas、内含 canvas 的容器，或 null（离屏；官方客户端无 DOM 会抛错）。

参数 类型 说明
dom HTMLCanvasElement | HTMLElement | null 绑 canvas 则指针事件 + 自动 putImageData；null 纯离屏
opts.width number 默认 300；必须 > 0
opts.height number 默认 150；必须 > 0
opts.dpr / devicePixelRatio number 默认 1 
const zr = init(canvas, { width: 480, height: 360, dpr: 1 });
const offscreen = init(null, { width: 480, height: 360 });

绑了 canvas 时，把 canvas.width / canvas.height 设成与 opts 一致；上屏不改位图尺寸。 对照 Bounding Box、 Hello World。

dispose(zr) / disposeAll() 官方

dispose 释放单个实例（也可用 zr.dispose()）。 disposeAll 清空全部实例与元素表，并解绑指针。

参数 类型 说明
zr facade ZRender 或 native handle 优先调实例 dispose；否则按 handle id 从注册表删除 
dispose(zr);
disposeAll();

getInstance(id) 官方

按实例 id 取回已包装的 facade；缓存没有再包一层 native handle。

参数 类型 说明
id number zr.id 
const again = getInstance(zr.id);

version 官方

字符串常量 '6.1.0'，对齐官方 zrender 版本号。

import { version } from '@wasm-zrender';
console.log(version); // '6.1.0'

registerPainter(name, Ctor) 降级

只把 painter 记进 Map。后端固定离屏 canvas，不会按名字切换 SVG / 其它 painter。

参数 类型 说明
name string painter 名，例如 'canvas'
Ctor 任意 仅存储，不会实例化 
registerPainter('canvas', function CanvasPainter() {});

registerFont(data, opts?) 补充

向全局 fontdb 注入 TTF / OTF / WOFF。未注册时含 Text 的 refresh 会 no default font found。完整规则见 字体引用。

参数 类型 说明
data Uint8Array 字体文件 bytes
opts.familyName string? 覆盖族名；不传则读 name table
opts.sansSerif string[]? 把 CSS sans-serif 映射到这些族名 
registerFont(bytes, {
  familyName: 'Noto Sans SC',
  sansSerif: ['Noto Sans SC'],
});

clearFonts() 补充

清空已注册字体，主要用于测试；会热更新已有实例的 fontdb。

clearFonts();
