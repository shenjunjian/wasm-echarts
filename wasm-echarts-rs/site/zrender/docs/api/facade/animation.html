动画与事件

不播中间帧：when().start() 立刻写入最后一组目标。 有 canvas 时绑定指针；mousemove 默认不上屏。

这是允许例外，不是未实现清单里的「以后再做」。 仓库要的是一帧终态图像，不是 rAF 循环。

el.animate(path?, looping?) 降级

返回 JS Animator。path 为 'shape' / 'style' 或空（整元素 attr）。looping 会记下但终态下无循环。

参数 类型 说明
path string? 属性路径
looping boolean? 忽略播放，仅保存 
circle.animate('shape')
  .when(400, { cx: 200 })
  .when(800, { cx: 320 })
  .start();
// 立刻停在 cx = 320

对照 animation。

Animator 链 降级

when 只保留最后一帧。start 写入目标后立刻 during(target, 1) 与 done。delay / stop 空操作。

方法 参数 说明
when(time, props) 毫秒被忽略；props 对象 覆盖上一组终态
during(cb) (target, percent) start 时 percent === 1
done(cb) () start 末尾调用
delay(time) 忽略 返回 this
start(easing?) easing 忽略 立刻终态
stop() — 空 
el.animate()
  .when(200, { x: 100 })
  .during((target, p) => console.log(p))
  .done(() => console.log('done'))
  .start();

对照 particles。

animateTo(target, cfg?) 降级

立刻 attr(target)，再调 cfg.during(this, 1) 与 cfg.done。没有缓动时间。

参数 类型 说明
target object 要写入的属性
cfg.during / cfg.done Function? 同步回调 
el.animateTo({ x: 80, y: 40 }, { done() {} });

zr.animation 降级

无帧循环。on('frame') / off 空操作。不要靠它做每帧 tick。

zr.animation.on('frame', () => {});

指针绑定 官方

init(canvas) 绑定 pointerdown/move/up/cancel，转成 zrender 事件。 add / attr / 非 mousemove 事件后自动 putImageData。 mousemove 本身不上屏（避免每帧整幅 RGBA 拷贝）；拖拽改位置时会刷。

宿主 行为
有 canvas DOM 指针 → 命中 → on 回调
init(null) 无监听；用 handler.dispatch 
zr.on('click', (e) => console.log(e.target && e.target.type));
el.on('mousedown', () => el.setStyle({ fill: '#ee6666' }));

对照 hit、bounding_box（拖拽）。

zr.handler.dispatch(name, event) 官方

官方 Handler 也有 dispatch。无 DOM / 测试时用它注入指针（wasm 离屏宿主靠这一条）。 坐标读 zrX/zrY，否则 offsetX/offsetY。

参数 类型 说明
name string 如 'click' 'mousemove' 'mousedown'
event { zrX, zrY } 逻辑坐标 
zr.handler.dispatch('click', { zrX: 40, zrY: 40 });

handler.setCursorStyle 官方

与 zr.setCursorStyle 相同，写到绑定 canvas 的 CSS cursor。

zr.handler.setCursorStyle('move');

图元 on / off / trigger 官方

回调存在 native registry，命中后 call1。无 canvas 时同样可用 trigger 或 handler.dispatch 走到目标。

rect.on('click', () => rect.useState('emphasis'));
rect.trigger('click');
rect.off('click');
