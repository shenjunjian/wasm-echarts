工具模块

实现在 js/tool/，按官方签名重写。 pkg 里的同名导出是空对象占位，不要从 pkg 调。

matrix 官方 仅 facade

3×2 仿射矩阵，布局 [a, b, c, d, tx, ty]。多数函数写 out 并返回它。

函数 签名
create () → [1,0,0,1,0,0]
identity copy clone (out, m?)
mul (out, m1, m2)
translate (out, a, [tx, ty])
rotate (out, a, rad, pivot?)
scale (out, a, [sx, sy])
invert (out, a)；不可逆返回 null 
import { matrix } from '@wasm-zrender';
const m = matrix.create();
matrix.translate(m, m, [10, 20]);
matrix.scale(m, m, [2, 2]);

vector 官方 仅 facade

二维向量 [x, y]。别名：length=len，dist=distance。

函数 签名
create set copy clone create(x?, y?) 默认 [0,0]
add sub mul div (out, v1, v2)
scale scaleAndAdd negate normalize lerp 标量或插值
len lenSquare dot distance distanceSquare 度量
min max applyTransform applyTransform(out, v, m) 
import { vector } from '@wasm-zrender';
const out = vector.create();
vector.add(out, [1, 2], [3, 4]); // [4, 6]

color 官方 仅 facade

函数 说明
parse(str, rgbaArr?) CSS 颜色 → [r,g,b,a]
stringify(arr, type) type 为 rgb / rgba / hsla…
lift / liftColor / toHex / modifyAlpha / modifyHSL 变亮变暗、改通道
lerp / fastLerp（fastMapToColor） 色标插值
lum / random 亮度；随机色 
import { color } from '@wasm-zrender';
color.parse('#5470c6'); // [84, 112, 198, 1]
color.lift('#000', 0.2);

path 官方 仅 facade

落到 Path + shape.pathData。

函数 参数 说明
createFromString(str, opts?) SVG d + 图元 opts 返回 Path 实例
extendFromString(str, defaultOpts?) 同上 返回可 new 的子类
mergePath(pathEls, opts?) Path 数组 拼接各 pathData
clonePath(source, opts?) opts.bakeTransform 拷 shape/style；默认也拷变换 
import { path } from '@wasm-zrender';
const p = path.createFromString('M0 0 L20 0 L10 20 Z', { style: { fill: '#91cc75' } });
zr.add(p);

util 官方 仅 facade

类型判断、clone/merge、数组工具、guid。实现按签名重写，不粘贴官方源码。

分组 导出
类型 isArray isFunction isString isStringSafe isNumber isObject isBuiltInObject isTypedArray isDom isGradientObject isImagePatternObject isRegExp eqNaN isArrayLike isPrimitive
对象 clone merge mergeAll extend defaults keys hasOwn assignProps createHashMap createObject setAsPrimitive
数组 / 函数 each map reduce filter find indexOf slice concatArray bind curry retrieve retrieve2 retrieve3
其它 guid logError assert trim normalizeCssArray inherits mixin createCanvas disableUserSelect noop 
import { util } from '@wasm-zrender';
util.merge({ a: 1 }, { b: 2 }, true);

morph 降级

签名齐全，不做真实形变。动画例外：立刻终态。morphPath 直接返回终点 path，并调用 during(1) / done。

函数 实际行为
morphPath(from, to, opts?) 返回 to
combineMorph / separateMorph 空 fromIndividuals，count 来自终点列表
alignBezierCurves 原样返回 [array1, array2]
centroid(array) 多边形质心（有实现）
isMorphing / isCombineMorphing 看 __morphT / __isCombineMorphing
defaultDividePath 返回 [] 
import { morph } from '@wasm-zrender';
morph.morphPath(fromPath, toPath, { done() { /* 立刻 */ } });

parseSVG 降级

能解析 g / path / 基础图形（rect、circle、ellipse、line、polygon、polyline）。 defs 渐变、text、clip 后置。非法 SVG 抛 Illegal svg。

参数 / 返回 说明
xml 字符串或 DOM
opt.width height ignoreViewBox ignoreRootClip 可选
返回 { root, width, height, viewBoxRect, viewBoxTransform, named } 
import { parseSVG } from '@wasm-zrender';
const { root } = parseSVG('<svg><circle cx="8" cy="8" r="6" fill="#91cc75"/></svg>');
zr.add(root);

showDebugDirtyRect 降级

离屏无 dirty rect。签名保留，空操作。

import { showDebugDirtyRect } from '@wasm-zrender';
showDebugDirtyRect(zr, { autoHideDelay: 500 });

setPlatformAPI 降级

官方用来换宿主实现。WASM 仍不读系统字体；这里只覆盖 createCanvas / measureText / loadImage / getTime （给 util 等 JS 工具用），不改变 cosmic-text 渲染。 

import { setPlatformAPI } from '@wasm-zrender';
setPlatformAPI({ getTime: () => 0 });
