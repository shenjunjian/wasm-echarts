样式与几何

Path 的 fill / stroke 可以是颜色字符串、渐变或 Pattern。 几何类 Point / BoundingRect / OrientedBoundingRect 对齐官方。

Path style 字段 官方

字段 默认 说明
fill / stroke 见图元默认 颜色、'none'、渐变、Pattern
lineWidth 1
opacity / fillOpacity / strokeOpacity 1
lineDash — 数组或字符串（'dashed' 等，按 lineWidth 展开）
lineDashOffset 0
lineCap / lineJoin butt / miter round / square；round / bevel
miterLimit 10
strokeFirst false 先描边再填充
shadowBlur / shadowOffsetX/Y / shadowColor 0 / rgba(0,0,0,0.3) blur 与 offset 全 0 则无阴影

CSS filter、conic gradient 后置。

rect.setStyle({
  fill: '#5470c6',
  stroke: '#333',
  lineWidth: 2,
  lineDash: 'dashed',
  shadowBlur: 8,
  shadowOffsetY: 4,
});

LinearGradient 官方

参数 类型 默认
x, y, x2, y2 number 0, 0, 1, 0（NaN 时回落到这些）
colorStops { offset, color }[] 可空，再用 addColorStop
globalCoord boolean false（相对包围盒） 
const g = new LinearGradient(0, 0, 1, 0, [
  { offset: 0, color: '#5470c6' },
  { offset: 1, color: '#91cc75' },
]);
g.addColorStop(0.5, '#fac858');
rect.setStyle({ fill: g });

RadialGradient 官方

r0 为内半径（官方有、vl-convert 缺，引擎已补）。

参数 默认
x, y, r 0.5, 0.5, 0.5
colorStops 可选
globalCoord false
r0 0 
const rg = new RadialGradient(0.5, 0.5, 0.5, [
  { offset: 0, color: '#fff' },
  { offset: 1, color: '#5470c6' },
], false, 0.15);
circle.setStyle({ fill: rg });

对照 hello_world。

Pattern 官方 补充

构造：new Pattern(image, repeat?)。repeat 默认 'repeat'。图像源与 Image 图元相同。

成员 徽章 说明
image / repeat 官方 canvas / img / 已解码像素
x y scaleX scaleY rotation 官方 图案变换
imageData imageWidth imageHeight 补充 裸 RGBA + 尺寸；Uint8Array 必带宽高 
const pat = new Pattern(canvasEl, 'repeat');
rect.setStyle({ fill: pat });

Point 官方

值对象。实例方法会改自身；静态方法（facade 挂上）操作任意 {x,y}。

构造 / 方法 说明
new Point(x?, y?) 默认 0, 0
set copy clone equal 赋值与比较
add sub scale scaleAndAdd negate normalize 向量运算
len lenSquare dot distance distanceSquare 度量
transform(m) 3×2 矩阵
Point.set/copy/add/… 静态，对 PointLike 
const p = new Point(3, 4);
p.len(); // 5
Point.add(p, p, new Point(1, 0));

BoundingRect 官方

方法 参数 说明
new BoundingRect(x, y, width, height) 四个 number
union / copy / clone / plain 另一矩形 / — plain 返回普通对象
contain(x, y) / intersect(other, opt?) 点 / 矩形 opt.touchThreshold
applyTransform(m) 3×2 就地变换
isFinite / isZero —
create(rectLike) / set(obj, x, y, w, h) 静态 facade 还补了 calculateTransform(out, a, b) 
const a = new BoundingRect(0, 0, 10, 10);
a.contain(5, 5); // true
const m = BoundingRect.calculateTransform([], a, new BoundingRect(0, 0, 20, 20));

对照 bounding_box。

OrientedBoundingRect 官方

方法 参数 说明
new OrientedBoundingRect(rect, transform?) 矩形 + 可选 3×2
fromBoundingRect(rect, transform?) 就地重建
intersect(other, mtv?, opt?) 可选最小平移向量 重叠时把 mtv 写成 {x,y} 
const obb = new OrientedBoundingRect({ x: 0, y: 0, width: 10, height: 4 }, [1, 0, 0, 1, 0, 0]);
