ZRender 实例

init 返回的 facade 包装 native handle。 图元用 add 挂上；绑了 canvas 时多数变更会自动上屏。

add / remove / clear 官方

增删根节点。有 DOM 时随后 putImageData。

方法 参数 说明
add(el) Element / Shape / Group 挂到根；返回 this
remove(el) 已添加的图元 从根卸下
clear() — 清空本实例图元 
zr.add(new Rect({ shape: { x: 8, y: 8, width: 80, height: 40 }, style: { fill: '#5470c6' } }));
zr.remove(rect);
zr.clear();

refresh() / flush() 官方 补充

官方返回 void。这里同步离屏绘制并返回 RGBA 字节数组（长度 width × height × 4）。flush 与 refresh 相同。

返回 类型 说明
像素缓冲 Uint8Array 行优先 RGBA；离屏路径用它 putImageData 
const rgba = zr.refresh();
ctx.putImageData(
  new ImageData(new Uint8ClampedArray(rgba), zr.width(), zr.height()),
  0, 0,
);

width() / height() / dpr() 补充

简写 getter。官方常用 getWidth() / getHeight()（同样导出，语义相同）。 

const w = zr.width();
const h = zr.getHeight();
const dpr = zr.dpr();

resize(opts) 官方

按 width / height / dpr（或 devicePixelRatio）重建离屏缓冲。规则与 init 的 opts 相同。

参数 类型 说明
opts.width number 默认 300
opts.height number 默认 150
opts.dpr number 默认 1 
zr.resize({ width: 640, height: 400, dpr: 2 });

findHover(x, y) 官方

在逻辑坐标上做命中（kurbo，不靠浏览器 isPointInPath）。未命中返回 undefined。

参数 / 返回 类型 说明
x y number 逻辑坐标
返回 { target, topTarget } HoverResult；顶层与命中目标 
const hit = zr.findHover(40, 40);
if (hit) console.log(hit.target.type);

对照 hit 示例。

on / off / trigger 官方

实例级事件。有 canvas 时 facade 绑定 pointer，再转成 zrender 事件名。无 DOM 时用 zr.handler.dispatch。

方法 参数 说明
on(event, handler) string, Function 注册；js_sys::Function 存在 registry
off(event?, handler?) 事件名可选；handler 可选 不传 handler 则清该事件全部监听
trigger(event, packet?) string, 任意 手动派发 
zr.on('click', (e) => console.log(e.target));
zr.off('click');

setBackgroundColor / getBackgroundColor 官方

CSS 颜色字符串；null / undefined 清掉背景。绑 canvas 时立刻上屏。

zr.setBackgroundColor('#f5f5f5');
zr.getBackgroundColor(); // '#f5f5f5'

setCursorStyle(cursorStyle) 官方

有 canvas 时写 canvas.style.cursor。空值当 'default'。

zr.setCursorStyle('pointer');

configLayer(zLevel, config) 降级

官方用来配分层 canvas。这里没有独立 layer：调用后只触发一次 paint_if_bound（有 DOM 就上屏），忽略 zLevel / config。 

zr.configLayer(1, { motionBlur: true });

painter 降级

占位对象：type === 'canvas'，getViewportRoot() 返回绑定的 canvas。 getSvgDom() 只 console.warn 并返回 null（无 SVG painter）。 

zr.painter.getType(); // 'canvas'
zr.painter.getSvgDom(); // null，并 warn

handler / animation / id / dispose 官方

成员 说明
id 实例数字 id，给 getInstance
handler 见 动画与事件；无 DOM 时 dispatch
animation 无帧循环；on('frame') 空操作
dispose() 从实例表删除并释放 native
