Element / Displayable / Path / Group

原型链对齐官方：Shape → Path → Displayable → Element；Group 直接 extends Element。

变换与通用属性 官方

读写走 JS getter/setter，再 _syncNative。skewX/Y、anchorX/Y 后置。

属性 默认 说明
x y 0 平移；也可用 position = [x, y]
scaleX scaleY 1 缩放
rotation 0 弧度
originX originY 0 变换原点
name '' 给 childOfName
ignore / silent false 不绘制 / 不响应命中
draggable false true 或 'horizontal' / 'vertical'
id / type — 只读，来自 native 
rect.x = 24;
rect.position = [24, 16];
rect.rotation = Math.PI / 8;

attr(key, value) / attr(obj) 官方

双参数与对象两种写法。clipPath 走 setClipPath / removeClipPath。

参数 类型 说明
keyOrObj string | object 属性名或补丁对象
value 任意 仅 attr(key, value) 时使用 
el.attr('x', 10);
el.attr({ y: 20, silent: true });

hide / show / clipPath 官方

hide/show 即改 ignore。clip 对 Group 子树也生效。

方法 参数 说明
setClipPath(clip) 图元 把 clip 的 native handle 交给引擎
getClipPath() — 返回 JS 侧保存的 clip
removeClipPath() — 清除 
circle.setClipPath(new Heart({ shape: { cx: 40, cy: 40, width: 60, height: 70 } }));
el.hide();
el.show();

对照 clip_path。

state 官方

JS 侧保存 states / currentStates，合并后再 setStyle / setShape / attrKV。首次 useStates 会快照 normal。

方法 参数 说明
ensureState(name) string 没有则建空对象并返回
getState(name) string 取已登记的 state
useState(name, keep?) 名 + 是否叠加 空名等价 clearStates
useStates(names) string[] 按序 merge
clearStates() — 恢复 normal
removeState / toggleState 名 / 名+enable 从当前列表删或加
hasState() — currentStates.length > 0 
rect.ensureState('emphasis').style = { fill: '#ee6666' };
rect.useState('emphasis');

对照 state 示例。

Displayable 官方

增加 z / z2 / zlevel / invisible 与 setStyle。attr('style', patch) 走 setStyle。 new Displayable() 不建 native。

方法 参数 说明
setStyle(key, value) / setStyle(obj) 同 attr 合并进 this.style 再同步 native 
rect.setStyle('fill', '#91cc75');
rect.setStyle({ stroke: '#333', lineWidth: 2 });

Path 官方

new Path(opts) 才建 native。setShape 双参数；setStateStyle 委托 native。

path.setShape('x', 10);
path.setShape({ width: 80, height: 40 });

Path.extend(defaultProps) 降级

可定义子类。若提供 buildPath(ctx, shape)，用 JS PathRecorder 录成 SVG shape.pathData，再交给通用 Path。 不走官方完整 PathProxy。 

const Diamond = Path.extend({
  type: 'diamond',
  shape: { x: 0, y: 0, w: 40, h: 40 },
  buildPath(ctx, shape) {
    ctx.moveTo(shape.x, shape.y);
    ctx.lineTo(shape.x + shape.w, shape.y + shape.h / 2);
    ctx.closePath();
  },
});

Group 子树 官方 仅 facade

new Group(opts) 立即建 native。子树列表在 JS （_children）；pkg 的 Group 没有这些方法。

方法 参数 说明
add(child) 图元 已有 parent 会先卸下
addBefore(child, next) 新节点、已有兄弟 next.parent 必须是 this
replace / replaceAt 旧/新 或 新+index 替换子节点
remove / removeAll 子 / — 卸下并清 parent
children() — 浅拷贝数组
childrenRef() — 内部数组引用
childAt(i) / childOfName(name) / childCount() 下标 / 名 / — 查找
eachChild(cb, ctx?) (child, i) 只扫直接子节点
traverse(cb, ctx?) (child) → stop? 深度优先；回调返回真则不进该 Group 
const g = new Group({ x: 10 });
g.add(new Circle({ shape: { cx: 20, cy: 20, r: 10 } }));
g.eachChild((child) => child.silent = true);

对照 shapes、bounding_box。

事件与包围盒 官方

on / off / trigger 委托 native。getBoundingRect() 返回 native BoundingRect。

el.on('click', () => el.setStyle({ fill: '#ee6666' }));
const box = el.getBoundingRect();
