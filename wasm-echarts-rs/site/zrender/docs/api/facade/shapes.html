图元（Shape / Text / Image）

各 Shape 的 shape 字段以 bridge/shape.rs 为准。 默认 style：Line 等描边图元 stroke 无 fill；Text 默认 fill #000。

描边默认（stroke: '#000'、fill: null）的类型： Line、Polyline、BezierCurve、Arc、 Rose、Trochoid。其余 Path 默认填充 #000、无描边。

Rect / Circle / Ellipse / Ring 官方

类 shape 字段 默认
Rect x y width height r r 为圆角，数字或数组
Circle cx cy r 全 0
Ellipse cx cy rx ry 全 0
Ring cx cy r r0 内半径 r0 默认 0 
new Rect({
  shape: { x: 8, y: 8, width: 80, height: 40, r: [4, 8, 4, 8] },
  style: { fill: '#5470c6' },
});

Sector / Arc 官方

类 字段 默认
Sector cx cy r r0 startAngle endAngle clockwise cornerRadius percent r0=0；endAngle=2π；clockwise=true；percent=1
Arc cx cy r startAngle endAngle clockwise 同 Sector 的角；描边默认 
new Sector({
  shape: { cx: 80, cy: 80, r: 60, r0: 20, startAngle: 0, endAngle: Math.PI, clockwise: true },
});

对照 sector。

Line / Polyline / Polygon / BezierCurve 官方

类 字段 说明
Line x1 y1 x2 y2 percent percent 默认 1；描边无 fill
Polyline points percent smooth smoothConstraint points 为 [x,y][]
Polygon points smooth smoothConstraint 闭合；smooth 默认 0
BezierCurve x1 y1 x2 y2 cpx1 cpy1 可选 cpx2 cpy2 percent 二次或三次；描边默认 
new Line({ shape: { x1: 0, y1: 0, x2: 80, y2: 40 } });
new Polygon({ shape: { points: [[0, 0], [40, 0], [20, 30]], smooth: 0.3 } });

Star / Isogon / Heart / Droplet / Rose / Trochoid 官方

类 字段
Star cx cy n（默认 3）r 可选 r0
Isogon x y r n
Heart / Droplet cx cy width height
Rose cx cy r（数组）k n（默认 1）；描边默认
Trochoid cx cy r r0 d location（location 默认 'out'）；描边默认 
new Star({ shape: { cx: 60, cy: 60, n: 5, r: 40, r0: 18 }, style: { fill: '#fac858' } });

Path / CompoundPath 官方

类 字段 说明
Path shape.pathData SVG path 字符串
CompoundPath shape.paths 子 path 数组：带 type+shape，或直接 pathData 
new Path({ shape: { pathData: 'M0 0 L40 0 L20 30 Z' } });

对照 shapes。

Text 官方

默认 style.fill = '#000'。渲染前必须 registerFont。引擎当前解析的文本字段： fill / textFill、fontSize（默认 12）、 fontFamily（默认 sans-serif）、 align / textAlign、 verticalAlign / baseline。RichText / textContent 后置。

字段 说明
style.text 字符串内容
style.x style.y 文本锚点（与元素 x/y 叠加） 
new Text({
  style: { text: 'wasm-zrender', x: 24, y: 48, fontSize: 18, fontFamily: 'Noto Sans SC' },
});

对照 text。

Image / TSpan 官方

Image 的 style.image 须是已 decode 的 HTMLImageElement / HTMLCanvasElement，或带 imageWidth / imageHeight 的 Uint8Array。 URL 字符串同步路径会失败。

字段 说明
style.x y width height 绘制矩形；宽高可省略（用源尺寸）
style.sx sy sWidth sHeight 源裁剪
TSpan 存在构造；富文本自动布局后置 
new Image({
  style: { image: imgEl, x: 0, y: 0, width: 80, height: 80 },
});

IncrementalDisplayable 降级

facade 可构造，语义是普通 Group（绑 native.Group），不是增量图层。 pkg 的同名类构造抛错。

方法 说明
addDisplayable(el, notPersistent?) 持久或临时列表，并 add 到 Group
clearDisplayables / clearTemporalDisplayables 卸下子节点（含官方拼写 clearDisplaybles）
getCursor / innerAfterBrush 游标只在 JS 侧走动，不改变绘制策略 
const inc = new IncrementalDisplayable();
inc.addDisplayable(new Rect({ shape: { x: 0, y: 0, width: 10, height: 10 } }));
