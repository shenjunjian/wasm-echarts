API 参考

默认走 JS facade（@wasm-zrender）。 pkg/ 是 wasm-bindgen handle，单独成章。

两层入口

层 导入 给谁用
JS facade import initWasm, { init, Rect } from '@wasm-zrender' 业务代码。有原型链、工具命名空间、官方签名。
pkg 导出 不要从业务直接 import '../pkg/wasm_zrender.js' 调试、echarts 注入 native、或绕过原型链。

每条 API 带徽章：官方 对齐 zrender-master 的 export.ts / zrender.ts / Element.ts； 补充 是 wasm-zrender 多出来的； 降级 签名在、语义弱于官方。

JS facade 分页

  • 总览与约定 — 导入、default、_bindNative
  • 生命周期 — init / dispose / registerFont
  • ZRender 实例 — add / refresh / 事件
  • Element 系 — 变换、state、Group、Path.extend
  • 图元 — Shape / Text / Image 字段
  • 样式与几何 — 渐变、Pattern、Point、包围盒
  • 工具模块 — matrix / vector / color 等
  • 动画与事件 — Animator 终态、Handler.dispatch

pkg 导出分页

  • 总览与何时使用 — 注入 native、无原型链、何时才碰 handle
  • 顶层函数与 ZRender — 同名但返回 handle；无 version / painter
  • 图元与样式类 — 无 JS getter；Group 无遍历
  • 空壳与不要直接用的符号 — 空 tool、抛错基类、仅 Rust 符号
